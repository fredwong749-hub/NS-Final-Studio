# 剧本镜头 → 图片：画面说明层（Shot Visual Spec）

> 2026-10-30。依据：《为他而骚 （剧本和镜头）v2》各镜 img/motion 原文、《image提示词》§1.2 拼装公式与 §2.2、《3提示词纠正器》、docs/REQUIREMENTS.md（A2/A4/A6/B1/C1/C3/C5）。
> 原则：**剧本原文一字不改**（§2.2 透传）；在原文之上加一层“图片模型能执行的画面说明”，并在画布上与原文并排、可人工修改。

## 1. 为什么需要这一层

剧本 img 是导演分镜写法，直接喂给图片模型会丢细节：

| 类型 | 例子 | 处理 |
|---|---|---|
| 时间先后 | ep49-S4「端餐盘刚坐下——微信亮起」 | 只取一个瞬间（首帧 = 动作起点） |
| 导演意图/比喻 | 「观众的情绪代餐」「像递一份合约」「镜像呼应」 | 译成可见构图，译不出放 notes，不进提示词 |
| 内心状态 | 「望着虚空想答案」 | 译成表情/视线/姿态 |
| 特殊手法 | 双重曝光（ep07-S2）、蒙太奇四格（ep16-S1）、慢镜定格 | 双曝光：两层合成；蒙太奇：拆格或取主格；定格：取峰值瞬间 |
| 屏幕文字 | ep34-S2 屏幕「在看。」 | 该镜单独放开“无文字”，只允许剧本指定文字 |
| 镜面/倒影 | ep03-S6、ep04-S6 | 简化描述 + 质检重点 |
| 首帧与动作错位 | ep40-S5 img 写结尾状态，motion 从“听完”开始 | 首帧取 motion 起点，尾帧取 motion 终点 |

## 2. 画面说明字段（每镜一份，JSON）

| 字段 | 内容 | 来源 |
|---|---|---|
| shot_size / angle / lens | 景别、机位、焦段光圈 | img/motion 原文 + 全局风格（徕卡 S★：50mm f/2、焦点锐利、暖调通透（项目方 11-01 L-087 选 R0 不变）） |
| first_frame | 动作起点：人物、姿态、手的位置、表情、视线 | motion 起点 + img |
| last_frame | 动作终点（同场景同人物同服装） | motion 终点 |
| characters | 出场角色及各自造型（脸底板、服装、鞋、美甲、妆容、D 状态） | 角色锁 + data/looks |
| scene | 场景锁（地点、布景、道具、时段），同场景镜头共用场景参考图 | img + 场景资产 |
| lighting | 剧本写的光源（警示黄灯/霓虹/钠光/台灯）+ 全局浓郁色调，剧本光源优先 | img |
| composition | 9:16 构图、主体位置、前后景 | img + 纠正器 1.4 |
| technique | 双曝光/蒙太奇/定格/剪影/屏幕文字 等 | img |
| on_screen_text | 剧本指定的屏幕文字（唯一允许的文字） | img/对白屏幕上 |
| notes | 比喻、导演意图等不进提示词的内容 | img |
| facts | 必须出现的名词/数字/颜色清单（质检逐条核对） | img 原文抽取 |

规则：facts 里的名词、数字、颜色不得改动或遗漏；不得新增剧情；成人镜头同样适用（由项目方启动渲染）。

## 3. 生成流程

1. 确定性解析（景别、运镜、技术手法、角色、屏幕文字）→ 2. 文字模型按上表生成画面说明（JSON schema，本地/项目方配置的写作模型）→ 3. 校验 facts 全覆盖 → 4. 拼装首帧/尾帧提示词：触发词 → 角色 DNA → 景别机位 → 人物造型 → 姿态表情 → 场景 → 光线 → 镜头焦外 → 色调 → 画质 → 5. 每镜 3 候选 + 看图模型逐条核对 facts + 人脸/色调/锐度焦外评分，≤3 轮 → 6. 画布并排显示：剧本原文 / 画面说明 / 最终提示词 / 候选与分数。

## 4. 场景资产

同一地点先做场景底板（无人物或人物虚化）：写字楼大堂旋转门、电梯轿厢、出租屋餐桌/厨房/卧室/浴室、顾沉家客厅、化妆品专柜、员工食堂、出租车后座……同场景镜头用它作参考图之一，保证布景与光线前后一致。

## 5. 试点
