# v1 收尾接口契约（fredw-92 定，前后端 agent 共同遵守；实现中如需改动，在本文件末尾“变更记录”追加并在 CHANGELOG 说明）

所有新接口挂在 ns_api（:8800），JSON；错误用 HTTPException(detail=中文)。不做成人 / 内容拦截。

## A. 模型与 API 配置（W1）
- `GET  /api/llm/providers` → `{providers:[{id,name,base_url,models:[...],default_model,has_key:bool,timeout_s,params:{temperature,max_tokens,reasoning}}], purposes:[{id,label,provider,model}]}`；永不返回密钥。
- `PUT  /api/llm/providers/{id}` body `{name?,base_url?,models?,default_model?,timeout_s?,params?,api_key?}`（api_key 只写进 config/llm_providers.local.json）。
- `PUT  /api/llm/purposes/{purpose}` body `{provider,model}`；purpose ∈ script_write | script_repair | director_boost | lora_llm | prompt_rewrite。
- `POST /api/llm/providers/{id}/test` → `{ok,latency_ms,detail}`（发一条极短请求）。
- `GET  /api/render/endpoints` → `[{id:"image"|"video",url,gpu,reachable,detail}]`；`PUT /api/render/endpoints/{id}` body `{url}`。
- 每处 ⚙ 覆盖：调用模型的接口都接受可选 `llm:{provider,model,params}`。

## B. 剧本创作（W1，扩展现有 /api/script-chat）
- `POST /api/script-chat/sessions` body 增加 `{outline?, episodes?:[from,to], shots_per_ep?, seconds_per_shot?, rules?, llm?}`。
- 现有 `POST /sessions/{sid}/chat` 接受 `llm?`；`POST /api/script-chat/sessions/{sid}/to-inbox` → 把草稿登记为导入候选（不自动导入）。
- `POST /api/script-chat/ab` body `{outline, episodes, llm_a, llm_b}` → 两个会话 id。

## C. 出图与精修循环（W2）
- `POST /api/shots/{id}/frame-jobs` body `{stage:"first"|"last", mode:"regen"|"instruct"|"refs", parent?: take_n, prompt?, instruction?, strength?: "small"|"medium"|"large", refs?: [{asset_id|path, role:"identity"|"style"|"color"|"item"}], seed?, gpu?: 0|3, llm?}` → `{job_id}`；结果是一个新 take：`Take` 增加 `parent:int|None, mode, instruction, strength, refs:[...]`。
- `GET  /api/jobs/{job_id}` → `{state:"queued"|"running"|"done"|"failed", take?, error?, gpu, eta_s?, started_at?}`；`POST /api/jobs/{job_id}/cancel`。
- `POST /api/shots/{id}/takes/{stage}/{n}/lock`（定稿）/ `.../unlock`；定稿首帧变化 → 尾帧、视频标过期。
- 版本链：`GET /api/shots/{id}` 的 takes 已有；新增字段 parent/mode/instruction/strength/refs/locked。

## D. 视频（W3）
- `POST /api/shots/{id}/video-jobs` body `{parent?, prompt_override?, seed?, steps?, seconds?, lora_strength?, gpu?: 3|0, loras?: [{name, strength}]}`（loras 见变更记录 fredw-92/VB）→ `{job_id}`；要求首尾帧已定稿（否则 409 写明缺什么）。
- 结果 take stage="video" 带 `params`；同样走 `/api/jobs/{id}`。

## E. 参考切换与资产（W5）
- ShotEdit 增加 `ref_overrides: {characters: {<char_id>: {look?: str, parts?: {outfit?,shoes?,makeup?,nails?,hair?,accessory?: asset_id}}}, scene?: plate_id|"none"}`；场景层存 episode_edit.json `scene_overrides: {<scene_id>: 同结构}`。
- `GET  /api/shots/{id}/refs` → `{characters:[{id,name,effective:{look,parts:{...},images:[...]},source:"episode"|"scene"|"shot",options:{looks:[...],parts:{outfit:[...],...}}}], scene:{effective,options}}`。
- `POST /api/shots/{id}/refs/preview` body `{scope:"shot"|"scene"|"episode", change:{...}}` → `{affected:[shot_ids], stale:[shot_ids], continuity_warnings:[...]}`；`POST /api/shots/{id}/refs/apply` 同 body + `{rerender_first?:bool, by?}`（scope=episode 需 by=owner）。
- 资产：`GET /api/assets/characters/{cid}`（形象、部件、参考图、版本、出现集数）；`POST /api/assets/{asset_id}/refs`（multipart 上传，role）；`POST /api/assets/{asset_id}/refs/from-take` body `{shot,stage,n,role}`；`POST /api/assets/{asset_id}/gen-jobs` body `{base?, refs:[{ref_id,role}], prompt, strength, gpu?}` → job；`POST /api/assets/{asset_id}/versions` body `{take|job result, label}`。
