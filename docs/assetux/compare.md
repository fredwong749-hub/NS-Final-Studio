# 人物资产管理：旧版好在哪、新版差在哪（ASSETUX，2026-10-31 ~ 11-01）

- 起因（项目方原话）：
  - “这个资产管理没有之前做的好，乱七八糟的，这个 iteration 做得不好。继续 iterate 一下这个版本，这个人物资产管理，我不接受这个 UI、UX 包括里面的功能。”
  - “我要把一些图片放进去，比如……我要添加这个鞋子进去作为资产，我怎么做呀？”
  - “很多事情只有一个确认按钮就可以，甚至不用确认按钮就行了，就是我选这个图按一下就可以了……系统是在我 login 的，意味着我所做的所有行为都是我个人行为，所以你不需要每个东西都要打上一个字。”
- 对比对象：
  - 旧版（项目方认为更好）：旧资产库 `/?view=assets`（归档代码 `data/_archive/20261031/code/apps_web/src/components/assets/{AssetsPage,CharacterCard,parts}.tsx`）、UX4 分身做的角色卡（`apps/web/e2e/ux4/f_after_assets_1440.png`）、UX5 实拍 `apps/web/e2e/ux5/a_old_assets_1440.png`。
  - 新版（UI5 / UI6 / UIRSI 改过的 `#/assets`）：`apps/web/e2e/uirsi/r22_assets_1440_dark.png`，以及本轮改前实拍 `apps/web/e2e/assetux/before_*.png`。
- 本文只讲界面怎么组织、怎么操作；不写也不评价剧本和画面内容。

## 1. 旧版好在哪

| # | 旧版的做法 | 为什么好用 | 证据 |
|---|---|---|---|
| O1 | 左栏一列人物（头像 + 名字 + “1 造型 · 88 单品 · 缺 5”） | 进来就是“人”，点谁看谁；缺什么在列表上就看得到 | ux5/a_old_assets_1440 |
| O2 | 右侧一大张人物图（9:16，占半屏）+ 造型 A/B/C 切换 | 先看到“她长什么样”，再看细节；层级清楚 | ux5/a_old_assets_1440 |
| O3 | 造型下面按槽位排：服装 / 鞋 / 美甲 / 发型 / 妆容 / 饰品，每格一张图或“＋ 未设” | 一眼看出这套造型缺哪一件；空格直接点就能补 | ux5/a_old_assets_1440 |
| O4 | 角色卡四格视图：正面 / 半身 / 全身 / 转面，带白底标签 | 大图、对比方便 | ux4/f_after_assets_1440 |
| O5 | “用这些参考出图（2 张）”直接在造型下面 | 资产和用途在一页里 | ux5/a_old_assets_1440 |

| # | 问题 | 项目方的感受 | 证据 |

## 3. 这一版怎么改（对应上面的问题）

| 问题 | 改法 |
|---|---|
| N1 / O1 | `#/assets` 默认打开人物页；左栏上半是“人物 · 当前剧”（林晚、顾沉、陈宇、阿岚，头像 + 套数 + 单品数 + 缺图红点），下半“其他资产”（场景、道具、风格、声音、提示词模板）；“全部资产（卡片总览）”留在左栏底部 |
| N2 / O2 / O4 | 一个人一页长滚动：身份脸（当前 + 候选）→ 造型 A / B / C（每套一行：当前设定图大图 16:9 + 候选 + “这套造型包含”部件清单）→ 衣橱单品 → 声音 → 出场 → 最近操作；页内锚点条吸顶 |
| N3 | 点候选图 = 立即生效；底部提示条“撤销”10 秒；操作人取登录账户，自动记“谁、何时、做了什么” |
| N4 / O3 | 衣橱默认只显示当前剧造型用到的单品 + 新上传的；旧单品折叠成一行“显示以前登记的单品（85 件）”；每件单品卡上 A / B / C 三个按钮，点一下挂到 / 拿下那套造型 |
| N5 | “＋ 添加单品”（人物页右上、衣橱末尾）、整页拖放、Ctrl+V 粘贴 → 一个对话框：图 + 类别（衣服 / 鞋 / 饰品 / 身体饰品·穿环 / 指甲 / 包 / 发型 / 妆容）+ 名称 + 备注 + 挂到哪套造型（可多选、可不挂）→ “添加” |
| N6 | 部件状态只用出图解析器 `look_inventory` 的口径：单品图（绿）/ 仅设定图（黄，建议补单品图）/ 缺图（红，出图会拦下） |
| N7 | 人物页里直接列“出场：第 N 集 · M 镜”，镜头号点了回画布；声音卡显示音色和说明 |
