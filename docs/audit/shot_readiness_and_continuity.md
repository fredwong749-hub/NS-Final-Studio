# 镜头就绪闸门 + 镜头衔接规则（2026-10-30，项目方要求，claude-gpu3）

项目方原话：“每一集，每个镜头必须有首尾帧图片、镜头和剧本提示词、声音提示词、背景音乐提示词这些关键要素……如果没有，这个镜头必然失败。镜头和镜头之间串联也思考如何避免跳得离谱。这是最大 bug。”

审计结果见 `docs/audit/canvas_audit.md`（脚本 `canvas_audit.py`，可重复运行）。

## 1. 审计发现（2026-10-30 10:40）

| 问题 | 规模 | 原因 |
|---|---|---|
| H3 声音提示词、配乐 cue、BGM 提示词全部缺失 | 360/360 镜 | v2 剧本没有这些字段，只有 v3 才有；v3 正在 gpu3 生成（约 gpu3 22:30 完成） |
| 尾帧缺失 | 355/360 | 笔记本流水线不出尾帧；gpu3 尾帧刚开始批量出 |
| 首帧缺失 | 247/360 | gpu3 首帧批量刚到 ep05 |
| **同一镜头首帧和尾帧来自不同流水线** | ep01 S1、S2（首帧 laptop，尾帧/视频 gpu3） | 画布显示的首帧不是做视频用的首帧，视频看起来“跳” |
| 有视频的镜头 | 3/360 | — |

结论：在任何关键要素缺失的情况下出视频，结果必然失败。ep01 就是这样拼出来的。

## 2. 镜头就绪闸门（硬规则，渲染器和合成器都执行）

一个镜头**只有全部满足**下列条件才允许出视频：

1. 首帧 `frame.png` 与尾帧 `last.png` 都存在，且**来自同一个 take 链**（同一流水线、同一 takes.json；尾帧由该首帧编辑得到），都通过帧闸门（脸、发色、服装、虚化、色调、剧本要点）。
2. 剧本提示词：`img_prompt`（画面）、`motion_prompt`（镜头运动）、`duration`（时长）。
3. 声音提示词：`sound`，以及 `sound_h3`（H3 原生音频，只有林晚发声）；亲密镜头还要 `sound_intimate`。
4. 配乐：本镜 `music_cue`，以及本集 `music_bgm`。
5. 上一镜衔接检查通过（见第 3 节）。

任何一项不满足，镜头状态 = `blocked`，原因写进 `status.json` 的 `blocked_reasons`，画布上显示为红色并列出缺什么。合成器遇到 `blocked` 镜头只能出 `_PREVIEW_未完成`。

在 v3 导入之前，第 3、4 项对所有镜头都不满足，所以**视频一律等 v3**；首尾帧可以先做。

## 3. 镜头衔接（避免“跳得离谱”）

### 3.1 场景分组
同一集内，按剧本的地点、时间、人物把连续镜头分进同一 `scene_id`。分组从 v3 的镜头文字里自动判断：地点词相同、没有“次日/转场/闪回”等字样，就算同一场景。分组结果写进 `visual_spec.json`。

### 3.2 同一场景内锁定的东西
每个场景的第一镜首帧定稿后，生成一份 `scene_lock`，后续镜头必须保持一致：
- 服装：款式、颜色、材质，以及漆皮超短裙、高跟鞋的状态；
- 发型、妆容、首饰状态（集内 D 状态）；
- 地点与布景：用背景参考图；
- 光线：时段、主光方向、色温。

### 3.3 生成方式
- 同一场景的下一镜首帧，用**上一镜的尾帧作参考图**，以编辑方式生成（只改机位、景别、姿势），不再从零文生图。
- 镜头内的尾帧，由本镜首帧编辑到 motion 的结束状态，与现在做法相同。
- 跨场景（转场）的镜头不受此限，但服装和妆容按 looks 和集内状态继续锁定。

### 3.4 衔接检查（帧闸门新增）
比较上一镜尾帧和本镜首帧（同一场景）：
- 视觉模型检查以下几点（任何一项“否”即失败）：同一套衣服？同一地点？同一光线？
- 服装颜色检查：在人物区域比较 LAB 直方图，距离必须低于阈值。
- 背景相似度：背景区域的 CLIP 余弦相似度达到阈值（远景↔特写的景别变化允许较低阈值）。

失败就按 3.3 的方式重画本镜首帧；超过轮数，记入 `HARD_SHOTS.jsonl`。

### 3.5 视频层
- 转场按项目方 AGENT-3 规格用 0.3 秒溶解（项目方文档优先）。前提是衔接检查已经通过，溶解时不会露出不一致。
- 合成前，把相邻镜头的“上一镜最后一帧 / 下一镜第一帧”拼成一张衔接表，写进 `epXX/continuity_sheet.jpg`，QA 时人工抽看。

## 4. 画布上的显示（fredw-d9）
- 每个镜头卡片显示 8 项要素的勾或叉：首帧、尾帧、img、motion、时长、sound/H3、配乐 cue、本集 BGM，外加衔接状态。缺任何一项都显示红色，并写明缺什么。
- 首帧和尾帧显示的必须是**出视频实际使用的那一对**（gpu3 take 链），不能是笔记本旧帧。
- 每集顶部显示：就绪镜头数/总镜头数，以及衔接表。
