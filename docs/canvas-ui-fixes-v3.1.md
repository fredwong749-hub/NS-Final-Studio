# 画布 v3.1 细节修正（fredw-92，2026-10-31，依据真实画布截图 apps/web/e2e/*.png 逐张审）

项目方原话：“整个 UI/UX 里面还有很多分布的不合理，很多细节的不合理，以及逻辑上的不合理……比如说，每一集里面的视频为啥这么小？其他参考图为啥那么大？……整个创造流程中存在非常多的问题。”

## 0. 原则（所有改动都按这几条判断）
1. **大小按“此刻要判断什么”分配**：被判断的东西最大（审片：首帧 / 尾帧 / 视频；精修：当前聚焦的那一格）；辅助信息（人物参考、场景、资产缩略图）小。
2. **一样信息只出现一次**：不重复显示集标题、模式切换、镜号导航、提示文字。
3. **操作跟着对象走**：按钮写明作用对象（“重新生成尾帧”而不是“重新生成”），放在对象下面。
4. **说人话**：不出现 inputs_sha、owner、gpu3 / GPU3 混用、“有卡锁着闲置”等内部词。
5. **状态只有一个来源、不能自相矛盾**：不允许“已定稿 + 过期”同时出现、“已定 0”而实际已定稿、造型已确认却显示“造型待确认”。

## 1. 审片模式（apps/web/src/v3/ReviewRow.tsx、Canvas.tsx、LeftRail.tsx、status.ts）
- 1.1 视频格太小：首帧、尾帧、视频三格**同尺寸**（9:16，等高），视频格可直接播放（悬停播放 / 点击放大）。有视频时视频格加强调边框（成品优先）。
- 1.2 左栏人物大卡占满整列：审片和精修**默认收起**为 56 px 头像条（悬停显示名字和形象字母），用户展开后记住；无底图的场景不占卡位，合并成一行“场景 4 个（无底图）”。
- 1.3 一屏只能看 2 镜多：行高压到约 270 px，1600×900 下至少 3 镜完整可见；文字列固定行数（剧本 2 行、表情 1 行、对白 2 行），人物小卡与“首帧 ▸ / H3 ▸”开关放在同一行（不再单独占一块）。
- 1.4 每行右侧重复的“为什么卡住？”“双击 / Enter 精修”提示删除：状态胶囊本身可点开“为什么卡住”；快捷键说明只在帮助里。
- 1.5 页面里的“第 2 集 · 深夜外套”大标题与顶栏集选择重复：删页面标题，顶栏集名不截断（必要时缩短副信息）。
- 1.6 右下“先出首尾帧预演 / 出视频 (1)”是全局按钮、对象不明：只在片段条有多选时出现，写明“对已选 N 镜：出首尾帧 / 出视频”；无选择时不显示。
- 1.7 右下统计“已定 0”与实际不符：统计与状态点用同一套判定（status.ts），已定 = 首尾帧都已定稿（视频另计）。

## 2. 精修模式（apps/web/src/v3/edit/*）
- 2.1 三格等大、没有主次：中间改为“一个大格 + 两个中格”——当前聚焦的阶段（首帧 / 尾帧 / 视频；有视频时默认视频）放大到可用高度（约 600 px），另两格缩成约 200 px 高的预览，点哪个就把它放大。
- 2.2 操作对象不明：大格正下方放这一格的操作，按钮写全名（“修改首帧…”“重新生成首帧”“定稿首帧”/“重新出视频”“改参数重渲”）；候选 / 版本条只显示聚焦阶段的版本，缩略图至少 72 px 高。
- 2.3 右栏三段长提示词同时展开、难编辑：右栏“提示词”只显示聚焦阶段对应的那段——首帧 → 首帧提示词；尾帧 → 尾帧提示词；视频 → H3 四块（对齐句 / 画面 / 环境声 / 配乐分块显示）+ 视频参数；其余折叠。编辑框高度随内容，至少显示 12 行。
- 2.4 视频审片能力：大格播放支持循环、逐帧（, .）、0.5× 速度；“首尾对照”开关：视频第一帧 | 定稿首帧、视频最后一帧 | 定稿尾帧并排；与上一版视频并排对比（同步播放）。
- 2.5 “← 审片”按钮与右上“审片 | 精修”切换重复：保留右上切换，删“← 审片”。顶部“3 / 11 · ←→ 切换”与片段条重复：删。
- 2.6 本镜参考条（林晚 / 顾沉 / 场景）保持小卡（高 48 px），这是参考图该有的大小；无图的人物显示首字头像，不留大空块。

## 3. 资产页与资产编辑（apps/web/src/v3/pages/AssetsPage.tsx、v3/edit/AssetDrawer.tsx）
- 3.1 左侧 300×530 大头像太大、形象卡却是空的“A”：形象卡显示该形象的图（没有就用角色主图），头像缩到约 160 px 宽；人物切换条不被截断（可横向滚动并有左右按钮）。
- 3.2 资产编辑抽屉：参考图组用缩略图网格（每组显示已挂的图，空组显示“拖图到这里”）；先选图（上传 / 拖放 / 从版本选）再选用途，不要先选用途再选图；底图选项显示底图预览；“生成”结果直接显示在抽屉里并进修改链。
- 3.3 用卡标签：统一写“出图卡 GPU0”“视频卡 GPU3”，服务器名不出现在卡选择里。

## 4. 顶栏与全局（apps/web/src/v3/TopBarV3.tsx）
- 4.1 GPU 胶囊“GPU 2/3 忙 · 有卡锁着闲置”：改为“出图卡 空闲 / 忙 · 视频卡 空闲 / 忙”，点开看详情。
- 4.2 步骤条副文字（“11 镜待处理”“造型待确认”）要与真实状态一致（ep02 造型已确认），字号不小于 12 px。
- 4.3 渲染连接指示“出图未连上”与 /api/render/endpoints 同源（后端 F4 在统一探测）。

## 5. 逻辑
- 5.1 刚出的版本被标“过期”、定稿与过期并存（后端 F4 修根因；前端：已定稿且过期时只显示“过期·需重出”，不显示“已定稿”）。
- 5.2 预计时长用后端按历史算的 eta（F4），显示“约 14 分钟”而不是固定值。
- 5.3 出视频前若尾帧过期，按钮禁用并写明“尾帧已过期，先重出尾帧”。
