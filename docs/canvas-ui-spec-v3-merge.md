# 画布 v3：新设计（小云雀式）与旧设计合并（2026-10-30，fredw-92）

依据：项目方“UI/UX 和旧的设计合并一起，看看怎么 balance 起来”；旧要求见 docs/REQUIREMENTS.md E1–E7 与记忆“画布编辑器要求”（一镜一行、首尾帧大图、每镜必有字段、资产 tab）；新调研见 docs/canvas_research_v3.md；原型 apps/prototype-v3/。

## 1. 原则：保留旧设计的“信息”，采用新设计的“组织方式”

| 来自旧设计（保留） | 来自新设计（采用） | 去掉 |
|---|---|---|
| 一镜一行看整集（项目方选定） | 单镜精修：三区 + 底部片段条 | 镜头行上的状态标签墙 |
| 每镜必有字段：首帧、尾帧、剧本、表情、运镜、对白、本镜人物、提示词、状态 | 状态只用一个圆点 + 一句“下一步” | 四套导航（集列表、S1–S7 药丸、镜头行、检查器） |
| 版本历史、A/B 并排对比、回退 | 抽卡组“3 抽 · 当前 #2”，在组里选定 | 主按钮上的后台路由字样（“请 gpu3 出首帧”） |
| 规则机检、关口说明（S1–S5、§9A） | “为什么卡住”小窗里看，平时不显示 | 检查器常驻并重复行内内容 |
| 按集排造型（我们的差异点） | 角色卡大头像 + 形象字母 + 出现集数 | 28 px 人物小图标 |
| 衔接检查（上一镜尾帧 → 本镜首帧） | 行间一条细线，悬停看结果 | 衔接的大段文字 |
| 导入、A/B 剧本、GPU、文档等工具 | 顶部步骤条 ①–⑤，工具收进“工具”菜单 | 资产 / 剧本 / 更多 / 视图 四个下拉 |

## 2. 两种模式，同一份数据，一个键切换（L / Enter / 双击行）

### 审片模式（列表，进集默认）——旧“一镜一行”，按新风格重排
每行从左到右：
1. 首帧 | 尾帧：9:16 大图并排（每张约 240 px 高），点开全屏对比；视频为小缩略图 + 播放。
2. 信息区（定宽，不随原文变高）：
   - 第一行：镜号 · 景别 · 运镜 · 时长 · 地点 ＋ 状态点 ＋ 一句“下一步”（如“待你审首帧”）。
   - 剧本原文：两行截断，悬停或点开看全文。
   - 表情：一行；对白 / 独白：最多两行，标说话人。
   - 本镜人物：9:16 小造型卡（形象字母 A/B/C），不是文字标签。
   - 提示词：折叠为“首帧 ▸ / H3 ▸”两个开关，展开在行内。
3. 动作：一个主按钮（=下一步，如“审首帧”“出视频”），其余收进 ⋯。
行与行之间：衔接细线（绿 = 通过，灰 = 未检查，红 = 不通过），悬停看原因。
左栏可收成 56 px 头像条，给列表让宽度。

### 精修模式（单镜）——新三区
- 左：本集角色卡、场景。
- 中：首帧 | 尾帧 | 视频大图；下面是抽卡组（候选）；只有两个主按钮“修改诉求”“重新生成”。
- 右：旧检查器的内容按标签分组——提示词 | 版本（抽卡组 + 并排对比 + 回退）| 规则（§9A 机检、关口）| 高级（负面词、种子、参考图）。默认停在“提示词”。

两种模式底部都有片段条（缩略图 + 时长 + 状态点），多选后“先出首尾帧预演 → 出视频”。

## 3. 集头：“待你决定”条（旧 owner_actions）
只列项目方本人要拍板的事（S1 验收、造型确认、底图确认），带数量；没有待办就不显示。其他关口信息只在“为什么卡住”里看。

## 4. 资产页（旧资产 tab，换成小云雀角色卡样式）
角色卡：大头像、形象数、出现集数；点开是参考图、服装、高跟鞋、美甲、发型、造型 A/B/C，以及按集排期表（哪几集用哪套）；点“用到的镜头”反查。

## 5. 状态点与一句话（统一词表）
灰 未出 · 蓝 生成中 · 黄 待你审 · 绿 已定 · 红 失败（不再有成人锁（项目方 2026-10-30 夜：“关于‘成人’的内容自动跳过，我们暂时不看”））。一句话只说下一步，不说系统内部状态。

## 6. 本镜参考设定：按人物、按部件快速切换（项目方 2026-10-30）

项目方原话：小云雀可以“基于不同的人物，在当前的 setting（包括衣服、妆造、背景等）中，随意切换图片的 reference”；“每个镜头前，如果我对当前 reference 图片的 setting 不满意，就可以快速进行修改”。

### 6.1 三层继承：集默认 → 场景 → 镜头
- 集默认：项目方确认过的本集造型（looks 排期，现有的 look_confirmed）。
- 场景覆盖：同一场景里的几镜一起改（例如“写字楼这场林晚换高跟鞋”）。
- 镜头覆盖：只改这一镜。
每一层只记录“与上一层不同的部分”；卡片上用小角标显示“本镜改过 / 本场改过”，一键“恢复集默认”。

### 6.2 本镜参考条（精修模式，首尾帧上方；审片模式行内用小卡）
每个出场人物一张卡 + 一张场景卡，卡上是当前生效的参考图。点卡片弹出切换面板：
1. 整套形象：A / B / C 横排大图（标出集默认），点一下整套换掉。
2. 单件替换：服装、鞋、妆容、美甲、发型、饰品，每行一排资产库缩略图；只换这一件，其余保持当前形象。
3. 场景：底图的其他候选（机位、时段），以及“不用底图”。
4. 借用：“用 S3 的设置”（复制另一镜的整套参考）；在任一候选 / 定稿图上“设为参考”（相当于小云雀的截帧 → 资产）。
资产库里没有的东西不能在这里凭空新建，只能选已有资产；新资产走资产页（生成 / 上传，Image 2.1 / Klein）。

### 6.3 应用前先看影响面，再选范围
点“应用”时先显示：范围（只这一镜 / 本场景后续 N 镜 / 本集全部）、会变成“过期”的镜头（按 inputs_sha）、与相邻镜头的衔接风险（同一场景前后镜造型不同会标红）。
按钮：“应用并重出首帧”（默认）/ “只应用，稍后重出”。

### 6.4 权限与数据
- 镜头 / 场景覆盖：画布上项目方操作即可（不改集默认）。
- 改集默认（等于改造型确认）：必须项目方本人确认（by=owner），原 look_confirmed 失效并重新确认。
- 成人镜：与普通镜头完全一样，不加确认（项目方 2026-10-30 夜：“关于‘成人’的内容自动跳过，我们暂时不看”）。
- 数据：ShotEdit 增加 ref_overrides（{人物: {look, parts:{shoes, nails, …}}, scene: plate_id}），场景层存 episode_edit.json；编译器把覆盖并入 look_fragments 与参考图，inputs_sha 随之变化，旧 take 自动标过期。参考与 LoRA 的调度仍交给 Qwen / 渲染器，画布只记录“选了哪个已有资产”。
- 这是新功能（改 ShotEdit 结构），封板期只做原型；封板后与第 9 节第 3、4 步一起落地。

## 7. 图片精修循环 + 人物资产编辑（项目方 2026-10-30）

项目方原话：“对当前生成的画面不满意，希望可以在里面修改 image 图片、修改提示词、修改人物的 setting（服装、鞋子、makeup 等）……修改完之后，可以让 image editor 2.1 继续去修改图片，直到满意为止，我再进行图层视频的流程”；“把人物资产的修改功能也整合进去”。

### 7.1 一个循环，四种改法（精修模式，作用在当前选中的那张图上）
| 改法 | 做什么 | 后端 |
|---|---|---|
| 改提示词重出 | 编辑首帧提示词，整张重新生成 | qwen_t2i / 现有首帧流程 |
| 指令改图 | 在当前图上写一句修改要求（项目方原话，原样传），保留构图只改指定内容；可调“改动幅度”（小 / 中 / 大） | qwen_edit：当前图作底图（init_image）+ denoise 对应幅度 |
| 换参考再改 | 用第 6 节切换服装 / 鞋 / 妆 / 甲 / 发 / 场景后，把新参考图连同当前图一起送 Image 2.1 编辑 | qwen_edit 多参考（图1 = 当前图，图2… = 新参考） |
| 局部重绘 | 在图上涂一块区域 + 一句要求，只改这块 | 需要新增蒙版工作流（现在没有），封板后做 |
每次修改生成一个新版本，挂在“上一版”下面形成修改链：随时和上一版并排对比、回退到任一版、从任一版继续改。改法、原话、幅度、所用参考都记在这一版上（可复现）。

### 7.2 定稿关口：首帧 → 尾帧 → 视频
- 首帧满意 → “定稿首帧”。只有定稿后才能做尾帧（尾帧由定稿首帧编辑而来，C3），尾帧用同一套循环。
- 首尾帧都定稿 → 才出现“出视频”。改了已定稿的首帧，尾帧和视频自动标“过期”。
- 每一步都是项目方点；提示词与修改要求是项目方原话或 Qwen 写的内容，画布原样传给 Image 2.1，不改写、不评价。

### 7.3 人物资产编辑并进同一个循环
- 在本镜参考卡（第 6 节）上点“编辑这个资产”，打开同样的循环，但作用对象是资产图（例如林晚形象 B 的鞋）：指令改图 / 换参考 / 上传替换。
- 改完选择：“只这一镜用”（存为镜头覆盖）或“存为资产新版本”（资产库新增，形象数 +1）或“设为本集默认”（项目方本人确认，造型确认需重做）。
- 资产页的角色卡（第 4 节）也用这同一个编辑器，不另做一套。
- 资产主要靠 image2img 做（项目方 2026-10-30：“人物资产主要是靠图像生成，也就是靠 image2img 来做的…可以 upload 图片上去…提取图片里面人物的一些风格和色彩…用 image2img 来进行调整和增加”）：
  - 每个资产（角色形象、服装、鞋、妆、甲、发、饰品）可以挂多张参考图：上传、从定稿帧“设为参考”、从其他资产复制。
  - 每张参考图标明用途：“取人物 / 脸”“取风格”“取色彩”“取这一件（服装 / 鞋…）”；生成时按用途排成 Image 2.1 编辑的 图1、图2…，并在提示词里写明各图用途（提示词由项目方或写作方写，画布原样传）。
  - 一次生成 = 选底图（或不选，纯文生图）+ 参考图组 + 提示词 + 改动幅度 → gpu3 Image 2.1 Turbo → 结果进资产的修改链，满意后“存为资产新版本”。
  - 系统不做内容检测（项目方 2026-10-30 夜：“走一个没有成人检测的方向，先把基础流程跑完”）。

### 7.4 成本与安全
- 每次改图前显示要用哪张卡、预计时长；排队中可取消。
- 成人镜：与普通镜头完全一样，不加确认（项目方 2026-10-30 夜：“关于‘成人’的内容自动跳过，我们暂时不看”）；露骨红标的人工标记维持原处理，直到项目方另行决定。

## 8. 剧本创作页 + 统一的模型 / API 配置（项目方 2026-10-30）

项目方原话：“1. 提纲输入… 2. 模型设置：可以用千问，也可以用 DeepSeek 或者 MiniMax 对应的 LLM 来进行剧本写作。3. API 配置：我希望在每一个地方都有这样一个 API 的 configuration，以便我进行调整。”

### 8.1 剧本创作页（在现有 #/script-chat 上改，不另起一套）
1. 提纲输入：粘贴或上传提纲；填集数范围、每集镜头数 / 时长目标；选写作规则版本（现行 rules_v2）。
2. 模型设置（就在提纲下方）：服务商 + 模型 + 参数（温度、最大输出、是否开推理），走 gpu3 的 LLM 网关 Docker 调外部 API：DeepSeek、MiniMax、abliteration 等（2026-10-30 夜项目方撤下千问写作模型，不再有本地 Qwen 选项）；显示每家是否已配好 key、预计费用档。
3. 写作：流式输出 → 按集落进草稿 → 自动跑格式校验 → 一键“送到剧本导入”（仍由项目方在导入页确认）。
4. 同一份提纲可以分别交给两个模型写，结果直接进现有 A/B 剧本对比页。
系统只收发和校验格式，不读不改剧本内容（不变）。

### 8.2 统一模型与 API 配置
- 一份服务商清单：config/llm_providers.json（不含密钥：名称、base_url、模型列表、默认参数、超时），密钥只放 config/llm_providers.local.json 或环境变量；接口只返回“已配置 / 未配置”，永远不回传密钥（与刚修的“config/ 不对外提供”一致）。
- 预置：DeepSeek（OpenAI 兼容接口）、MiniMax（OpenAI 兼容接口）、abliteration；全部经 gpu3 的 LLM 网关 Docker 转发（项目方：“调度外部的 API 来进行写作和 Lora 训练的大语言模型”）。本地 Qwen 写作模型已撤下。DeepSeek / MiniMax 的地址和模型名以官方文档为准，配置时核对，不在代码里写死。
- 按用途指定默认：剧本写作、格式返修、导演加强、LoRA 训练用的 LLM（打标 / 规划）、首帧提示词改写……每个用途一行，选服务商 + 模型。
- 每处就地覆盖：画布里每个会调用模型的按钮旁放一个 ⚙，点开只改这一次（或“记为此处默认”）。
- 图像 / 视频也进同一页：Image 2.1（ComfyUI / qwen-image-api 地址）、H3、LoRA 训练节点；显示连通状态和“测试连接”按钮。
- 现有的 config/script_chat.json、director_boost_llm*.json、abliteration.local.json 迁移进来（保留旧文件读兼容一段时间）。

## 9. 落地顺序（封板后）
1. 状态点 + 一句话 + “为什么卡住”小窗（替换标签墙）。
2. 审片行重排（字段定宽、提示词折叠、主按钮=下一步）+ 底部片段条。
3. 精修模式与检查器标签化 + 图片精修循环（第 7 节：改提示词重出、指令改图、换参考再改；修改链、对比、回退；定稿关口）。
4. 本镜参考切换（第 6 节：三层继承、参考条、影响面预览）+ 资产编辑并进同一编辑器（7.3）。
5. 统一模型 / API 配置页 + 每处 ⚙ 覆盖（第 8.2 节），剧本创作页加提纲与模型设置（8.1）。
6. 集头“待你决定”条、顶部步骤条与“工具”菜单；资产页角色卡。
7. 局部重绘（蒙版工作流，需要 gpu3 新增 ComfyUI 流程）。
