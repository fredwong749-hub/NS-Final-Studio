> 起因：项目方认为画布"还是不好用，小云雀好很多"。
> 范围：只看**交互**，不看营销说法。已有的结论不重复，见 `canvas_research.md`、`canvas-ui-spec-v2.md`、`research/short_drama_platform_ui.md`。本文只补这几份文档里的**空白**。
> 方法：逐页读官方教程（小云雀教程中心共 14 篇，其中短剧相关 5 篇已读）和媒体实测。每条结论附来源链接、原文短引（不超过 15 字）和置信度。

## 0. 三句话结论

1. **小云雀的集编辑器只做一件事：一条片段轴加一个当前片段。** 左边是资产，中间是当前片段的脚本，右边是预览或对比；底部的片段轴放缩略图和时长，用来切换片段和多选。我们的画布一屏只能看到大约 1 个镜头，却同时摆了 4 套导航（左侧集列表、S1–S7 药丸、镜头行、检查器）和 5 种状态写法。主要差距在**信息分层**，不在功能多少。
2. **小云雀的状态表达很省**：分集只有「未解析 / 解析中 / 解析完成」三态，加一个批量的「重新解析」；片段上只有一个绿点。重做入口也只有两个，放在结果右上角：「修改诉求」和「重新生成」。我们每个镜头同时有红字、chip、✗未就绪、按钮文案、检查器的「未审」五处状态，而且把「gpu3 / 笔记本」这类系统路由信息写进了主操作文案。
3. **更正旧结论**：v2 规范里说"小云雀没有版本历史"，不够准确。它的画布会把**同一提示词多次生成的结果折叠成一组**，用户可以从**抽卡记录里指定一版**，之后的引用都以这一版为准（官方，见 §1.1-C）。它真正缺的是**故事板里的并排对比和回退**。我们要保留完整的版本对比，同时借用它"折叠成组 + 指定当前版"的做法。

### 1.6 横向小结：五家的共同点

1. **主编辑区只放"当前单元"**：小云雀放一个片段，LTX 放一个面板，OiiOii 放一个分镜。整集的总览交给**缩略图轴或网格**。
2. **状态写在卡片本身上**，样式很少：小云雀用「生成中」、绿点、待补充、三态，没有状态 chip 墙。
3. **重做入口固定在结果右上角，只有 2 个**（修改诉求、重新生成）。更深的修改去单独的工作台（画布、截帧注释）。
4. **资产是图卡**：卡上有主图、形象数、出现集数，点开能看到提示词。镜头通过 `@` 或按镜选形象版本来绑定资产。
5. **成本在提交前可见**（小云雀的积分预估、可灵按秒计费）。
6. **失败按单元隔离、批量重试**（小云雀的「重新解析」）。

### 1.7 没找到（不做补全）

- 小云雀片段卡和分镜卡的像素尺寸、缩略图大小。
- 生成中的进度条或排队号样式、单镜失败卡的样式、拒绝生成的文案。
- 故事板（不是画布）里的快捷键。
- 即梦短剧工作室的状态和版本 UI。
- 可灵 Director 模式的界面。
- LTX 是否有版本历史。

## 3. 建议照搬的 14 个模式

| # | 模式 | 出处（见 §1） | 解决我们的问题 | 具体做法 |
|---|---|---|---|---|
| P1 | **底部镜头轴**：整集每镜一张首帧缩略图（9:16，约 56×100），标镜号和时长，带状态点；点一下切换中栏 | 小云雀片段轴（官方配图） | Q1 Q2 | 拿掉 S1–S7 药丸。中栏只显示当前镜头，或当前镜加上下各半镜。轴固定在底部，高约 130 px |
| P2 | **中栏一次只放 1 个镜头，并且放大**：首帧和尾帧并排，各约 300×533；右边是镜头信息 | 小云雀"中间是片段脚本"、LTX 单面板 | Q1、E7②"图太小" | 和 E7① 一镜一行不冲突：用 `J/K` 或轴切换。另设"列表模式"给批量校对用 |
| P3 | **结果右上角只放 2 个重做按钮**：「改词重出」（跳到提示词）、「再抽一张」（同词换种子） | 小云雀修改诉求 / 重新生成（官方） | Q6、E7④ | 两个按钮悬浮在帧图右上角。检查器底部只留保存 |
| P4 | **同一提示词的结果折叠成一组，组内指定当前版** | 小云雀抽卡记录（官方） | Q8 | 帧槽左下角显示「3 抽 · 当前 #2」，点开横向展开候选；按 Enter 设为当前。和我们的版本历史打通 |
| P5 | **状态只写一处**：帧槽角上一个状态点（灰 = 未出、旋转 = 生成中、绿 = 已出、蓝勾 = 已审），轴上同色 | 小云雀"状态以卡片为准"、绿点 | Q3 | 删掉行内 chip 墙和「✗ 未就绪」行。缺什么，在对应槽位的空态里写。顶栏只保留全局队列数 |
| P6 | **空态 = 一句话 + 一个动作**，不讲后台路由 | 小云雀"待补充"＋批量补 | Q4 | 首帧空槽只写「未生成」和〔生成首帧〕。由哪台机器出放进 tooltip 或检查器的"技术"页签 |
| P7 | **人物用大图卡挂到镜头上**：每个出场角色一张 9:16 造型小图（约 64×114），标造型名；点开即资产卡 | 小云雀"分镜出现的角色妆造"、按镜选形象版本 | Q7、E3、E7⑤ | 卡上叠"本镜覆盖"角标；在造型图上点下拉，就能切换 A/B/C 形象 |
| P8 | **资产卡标"形象数 + 出现集数"**，点开先看原始提示词 | 小云雀"几个形象"、即梦"出现集数" | E5、E7⑤ | 角色卡：大定妆图 + 形象 A/B/C 页签 + 「出现：1–8, 17 集」，点集号跳转 |
| P9 | **从资产卡点一下，定位到用它的镜头** | 小云雀"点击卡片定位至画布" | E5 | 资产卡上加「用到的镜头 N」，点击后底部轴高亮这些镜头 |
| P10 | **多选后显示范围和成本，再提交** | 小云雀多选 + 积分实时更新、片段重拍计费预估 | Q10 | 在轴上 Shift / Ctrl 多选，浮出批量条：「已选 5 镜 · 预计 25 分钟 / GPU」〔出首帧〕〔出尾帧〕〔出视频〕 |
| P11 | **失败按单元隔离，"重试全部失败"一个按钮** | 小云雀「重新解析」（官方） | E4 耐用 | 集头显示「失败 2 〔全部重试〕」；失败镜在轴上标红点，悬停显示原因 |
| P12 | **集列表做成"下一步按钮"式** | 小云雀分集网格（官方配图） | Q11 | 每集一行：首镜缩略图 + 标题 + 一个主动作（「出首帧 3/7」「待审 4」「可串播」），替代 8 格进度条 |
| P13 | **截帧注释式改图**：在帧上圈出区域，旁边写要改什么 | 即梦截帧注释、小云雀精准截帧注释 | E7④ 改词→重出 | 检查器加"圈改"模式。圈选区和文字存为本镜修改诉求，再交给出图链路。内容本身由 Qwen 或人写，系统只负责传递 |
| P14 | **并排对比视图**：同步播放或同屏比较两版 | 小云雀"对比"视图（官方）、即梦编辑前后对比 | E7② 全屏对比、Q9 | 右栏加〔对比〕切换：当前 vs 候选，或 S(n) 尾帧 vs S(n+1) 首帧（接缝），支持全屏 |

**优先级建议**：先做 P1 + P2 + P5 + P6，这四项改的是骨架，能直接解决"乱"和"图小"。然后做 P3 + P4（改词→重出→选定的循环）。再做 P7 + P8 + P9（资产）。最后做 P10–P14。

## 4. 不要照搬的

| # | 小云雀或其他平台的做法 | 为什么不搬 | 我们怎么做 |
|---|---|---|---|
| N1 | 故事板里没有并排版本对比和回退，只在画布里能指定当前版 | 项目方要"改词→重出→对比→选定"（E7④）；360 镜要能回退 | 保留完整版本历史和 A/B 对比，只借用"折叠成组"的展示方式（P4） |
| N2 | 资料库一改，**全剧自动同步** | 已定稿的镜头会被静默改掉 | 沿用 v2：先列影响面，再选择性重渲，默认跳过锁定镜头 |
| N3 | 每一步都要确认才能往下走（线性向导） | 我们的剧本是离线导入的，镜头量大，需要非线性跳转 | 闸门只放在项目方确认点（例如 F2 成人批跑），其余随时可以跳 |
| N4 | 「与 AI 对话」直接改项目 | 违反 G2 / G5：Claude 不碰内容；对话写作只走 Qwen 的剧本对话框 | 不加通用对话改项目的入口；圈改注释（P13）只作为数据传给 Qwen 或出图链路 |
| N5 | 尾帧靠"截帧"，从视频里抽出来 | E1、C3 要求尾帧是独立资产，出视频前就要有 | 尾帧槽独立生成；截帧只作为一种来源 |
| N6 | 首尾帧被做成可选的衔接手段，或单独的生成模式 | E7① 要求每一镜固定显示首帧和尾帧两张大图 | 两个槽位常驻 |
| N7 | 自动在视频上烧字幕，再提供「擦除字幕」 | A3 要求不要字幕；应该从源头不出，而不是事后擦 | 不需要擦除按钮 |
| N8 | 积分计费的 UI | 我们是本地和 gpu3 算力，没有积分 | 把"成本"换成"预计时长 / 占用哪张卡"（P10） |
| N9 | 节点无限画布作为主界面 | 360 镜的量产管理需要集和镜的结构（v1 调研结论） | 画布最多作为单镜修复工作台，不作为主视图 |
| N10 | 在主界面暴露模型选择器（输入框左下角） | 我们的模型路由是系统规则（D1、G 系列），用户手选反而出错 | 模型和机器信息只放在检查器的"技术"页签里，只读 |
