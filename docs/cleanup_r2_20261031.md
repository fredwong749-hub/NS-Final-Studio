## 一、判定方法

- 度量：与 `tools/identity_metric.py` 同一口径——insightface buffalo_l（SCRFD det_10g 检测 + ArcFace w600k_r50 向量），余弦阈值沿用该工具注释：≥0.50 同人，0.30–0.50 相像，**<0.30 多半是另一个人**。本机没有 insightface 包，用 onnxruntime 直接跑同一组 onnx 模型（模型从 insightface 官方 v0.7 release 下载到临时目录；`~/.insightface/models/buffalo_l.zip` 是不完整的下载，没有动）。没有上 gpu33/gpu36。
- 身份参考（当前已登记）：`data/assets/identity_refs/{lin_wan,gu_chen,chen_yu}/*_face_ref2va.png`（项目方原话"林晚A-s202 顾沉s101 陈宇s202脸"）+ 林晚已确认定妆 `assets/characters/lin_wan/lin_wan.png`（与 ref2va 取平均）。自检：顾沉当前设定图 vs 参考 = 0.967；三人互相 0.06–0.43。
- 打分范围（764 张，不含 ep02）：`assets/characters/**`、`data/renders/ep01, ep03–ep60/**`、`data/renders_gpu3/**`、`previews/**`、`data/ab/night_assets/`。
  - 资产图：只和**本人物**的参考比（顾沉的图要像顾沉）。
  - take / 预览：画面里所有检测到的脸，对三个已登记身份取最高值；没有可检测的脸的不判定（保留）。
- 未登记人物：当前剧本 `globals.character_registry` 只有 林晚 / 顾沉 / 陈宇。
