## 3. 没改 / 改不了的

1. **任务②的两次滚动**：检查器首帧页的顺序是“对比位 → 版本条 → 提示词 → 底部操作”，候选出现在顶部而输入在下面。要省掉滚动得把检查器首帧页重排（提示词上移或版本条折叠），这部分是检查器逻辑（fredw-92 仍可能在改组件逻辑），本轮只改展示，没动结构。建议下一步：提示词框放在对比位正下方，版本条默认折叠。
2. **“整集出视频”按钮**：归 fredw-25，没碰批量出图菜单。
3. **资产页造型卡“默 默认 默认”重复**（字母 + 名称 + 默认徽章）：在 AssetsPage 逻辑里，没改。
4. **浅色主题下来源标签（gpu3 / 本地 / SOP）配色**：沿用 T59 的状态色规则，没另起配色。
5. **viewer / chatsess 两页没有改前截图**：这两页是改动开始后才加进截图脚本的。
6. **pytest**：`npx tsc -b --noEmit` 0 错，`npx vite build` 通过。pytest 第一次跑 19 个失败，全是依赖当前导入剧本的数据测试（`unknown episode: 17`、`test_real_script_shape` 等）——当时其他会话把当前剧本换成了只有 1 集的版本；剧本换回整剧后再跑：528 过 / 1 失败（`test_quality_v2::test_real_adult_shots_detected`，该测试文件正被其他会话修改，单独重跑 54/54 通过）。本轮没改任何 Python，也没导入剧本。
