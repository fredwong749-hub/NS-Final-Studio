# T59 画布重设计 · 设计稿（fredw-25）

打开 `index.html` 看全部 6 张截图（1600×900，无头 Chrome），点截图进入对应静态页。

| 方向 | 集视图 | 镜头检查器 | 资产角色卡 |
|---|---|---|---|
| 深色剪辑台 | dark/episode.html | dark/inspector.html | dark/assets.html |
| 浅色内容平台 | light/episode.html | light/inspector.html | light/assets.html |

## 第一原则：页面干净清晰（项目方）
- 每屏一个主角：集视图 = 首帧 + 尾帧 9:16 大图（400 px 高）；检查器 = 新旧版本并排对比；资产页 = 角色大图 + 造型。
- 字号 3 级（12 / 14 / 20）、正文 2 色、强调色 1 个；状态色只出现在状态标签和状态点上。
- 行内只放：镜号 · 景别 · 运镜 · 时长、剧本、对白 / 独白、造型（头像 + 造型名 + 单品小图）、一个状态；表情和提示词收进检查器。
- 不套卡片、不加框和徽章、不用表情符号；行与行之间用留白和一根分隔线（含衔接状态）。
- 操作只在选中行出现；主操作（再出一版 / 选定）固定在检查器底部右下角。
- 顶栏只有：集切换、三个入口（镜头 / 资产 / 剧本）、一个出图状态、审片、更多（总览 / 节点 / 项目 / 设置收进去）。

## 两个方向的区别
- **深色剪辑台**：平铺，无阴影，选中行只抬高一层底色，适合长时间看片。
- **浅色内容平台**（参考小云雀）：每镜一张白底卡片 + 柔和投影，导航为胶囊分段，选中卡片强调色描边。

## 文件
- `tokens.css`：颜色、字号、间距、圆角、阴影、布局尺寸（两个方向同名变量，值不同）。
- `ui.css`：公共组件（顶栏、左栏、镜头行、检查器、角色卡），只读 token。
- `build.py`：由 `data.json` 生成页面；`--shots` 截图到 `shots/`。
- `data.json` + `img/`：第 1 集真实数据和图片（缩成 JPEG）。

## 数据说明
- S1、S2 的当前首帧在 gpu3，取图时 gpu3 桥返回 502，稿里用本地最新版本（见 data.json `notes`）。
- 检查器里的“当前 v6 / 新 v7”是 S1 本地两个历史版本，用来示意“对比 → 选定”流程。
- 林晚只有一个命名造型“默认”（无预览图）；REF-LW-01/02 是参考图组，尚未建成造型，稿里如实标注。

## 第 ② 步：全站套用（2026-10-30，项目方选“两套都要，可切换，深色默认”）

- **主题**：`apps/web/src/theme.css`（两套 token，`<html data-theme="dark|light">`，旧变量名 `--bg/--fg/--line/--ok…` 作别名）；`apps/web/src/themeMode.tsx`（启动时定主题、localStorage `ns.theme` 全部 try/catch、`?theme=light|dark` 临时指定、`ThemeToggle` 按钮）。顶栏、剧本创作、项目页都有切换按钮。
- **写死颜色**：各 CSS 里状态色改为 `color-mix(in srgb, var(--c-ok) N%, transparent)`，浅色字改为 `--c-*-text`；看图器、图上遮罩两套主题都保持深色。
- **布局**：`apps/web/src/t59.css`（最后加载；按需加载页面的规则加 `:root` 前缀提高优先级）+ 少量 tsx 展示改动：
  - 顶栏：集切换｜镜头 · 资产▾（角色卡 / 人物管理）· 剧本▾（输入导入 / 创作 / A/B）· 更多▾（总览 / 项目 / 节点）｜视图▾（镜头行/表格、密度、过滤、检查器）｜一个出图与队列状态｜审片｜主题｜帮助。
  - 集头：标题 + 梗概（点开）｜镜头索引 S1…（状态点）｜批量出图▾｜串播｜本集信息▾（SOP、就绪、导演加强、配乐收在这里，有待你决定时显示数字）；第二行本集造型 + 就绪 / 审核数。
  - 镜头行：首尾帧大图；未选中行只留镜号、景别·机位·运镜、时长（剧本未写时标黄“剧本未写·默认”+ H3 帧数）、剧本、表情、对白、造型；来源 / SOP / 成人 / 加强徽章、就绪行、版本条、提示词只在选中行出现；图上只留“首帧 v8 / 尾帧”一个标签。
  - 检查器：头部一行镜号 + 景别·运镜·时长 + 审核状态，第二行集名、负责方（说明在悬停里）、通过 / 打回文字按钮；标签页与表单统一字号、去框。
  - 资产角色卡、剧本导入、剧本创作、人物管理、总览：去框去徽章，状态只用文字颜色。
