# 欲望感加强规则（首帧/尾帧生图用）

> 2026-10-30 项目方要求：剧本写得保守，做爱镜头和身材特写少；在剧本镜头提示词的基础上，把欲望感拉满，每张首尾帧写得更极致、更性感。本文件是 Frame Spec 编译器（fredw-d9 的 `ns_agent.frame_spec`）和 gpu3 出图循环共同遵守的规则。

## 不变的底线
- 全部角色是虚构成年人（林晚 22 岁，其余均为成年人）；画面里不得出现任何未成年特征。
- 剧本里的亲密行为都是双方自愿；加强的是**画面的欲望感**，不加入强迫、伤害、非自愿的元素。
- 不改剧情、不新增事件和人物：镜头里发生什么由剧本决定，加强的是**怎么拍、拍到什么程度**。新增做爱场次/镜头属于改剧本，由项目方在剧本里写，或在画布里新增镜头后再生成。
- 装饰状态、服装排期、首饰数量（乳环2、阴环4+1+4、每环一颗5mm黑球）、透明高跟、美甲照旧以剧本和排期为准。

## 按镜头类型加强

| 镜头类型（由 Frame Spec 判断） | 加强方向 |
|---|---|
| **日常/办公（衣着完整，ep01–ep08 等）** | 不脱衣，靠镜头语言出欲望感：贴身剪裁勾勒腰臀与胸线、裙摆下的长腿与透明高跟、低机位腿部线条、锁骨与颈线、湿润的唇、半垂的睫毛与回眸、指尖与美甲的特写、他人目光的停留；光线用暖色轮廓光勾身体曲线 |
| **暧昧/调情（触碰、对视、车内、电梯）** | 两人距离压到极近、呼吸可见、皮肤接触点特写（手指、颈侧、唇角）、潮红、微张的唇、汗湿的发丝、衣料滑落的边缘 |
| **独处/镜前/换装/穿孔** | 身材特写成为主体：曲线、皮肤质感（细汗、光泽、毛孔真实）、漆皮/乳胶的反光包裹身体、首饰在皮肤上的位置与反光；构图按时尚大片与情色摄影的标准，不遮挡 |
| **亲密/做爱（剧本写到的场次）** | 明确呈现：裸露的身体、结合与爱抚的关键部位、体位与身体交缠、汗水、潮红、高潮表情；每镜可见人数仍≤3；镜头按剧本的景别，必要时首尾帧取更紧的身体特写 |
| **事后/收尾镜** | 凌乱的床单、汗湿的皮肤、散开的蓝发、残留的痕迹、满足或复杂的表情 |

## 写法
- 首帧取动作起点里**最有张力的一瞬**，尾帧取结束时**情绪最满的一瞬**。
- 每张图的描述必须具体到：身体哪一部分在画面中心、皮肤与材质的质感、光如何打在曲线上、表情与视线。
- 措辞用摄影语言（“低机位仰拍，腿部线条拉长”“逆光勾出腰臀曲线”“汗珠在锁骨上反光”），不用空洞形容词（“很性感”）。
- 欲望感加强写在 Frame Spec 的 `desire` 字段里（与剧本事实 `facts` 分开），这样画布能看出哪些是剧本原文、哪些是加强部分，项目方可以逐镜调高或调低。
- 强度分级 `desire.level`：1 含蓄 / 2 性感 / 3 极致（默认按镜头类型取上表的最高档；项目方可在画布里逐集、逐镜调整）。

## 模型
- 首帧/尾帧：NoctQ V4（uncensored）为主，Qwen-Image 2.1 Turbo 用于完全着装的日常镜头；需要时叠加首饰/服装/姿势 LoRA。
- 视频：H3 FL2VA 由首尾帧锁定，视频提示词同步写入身体动作与表情的递进。
