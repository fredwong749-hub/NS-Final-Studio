# 新建剧本页 · 全自动写作面板 验收步骤（给项目方，HOLLYWOOD r9）

> 页面：`#/script-create?new=1`，顶部的“全流程自动”面板（UIRSI AutoflowPanel）。数据来自 `GET /api/script-autoflow/<剧目>`，
> 和 `data/pipeline/runs/<剧目>/autoflow.json`、`autoflow_epNN.json` 是同一份。测试期写作由 Claude 写手完成（L-109），不花外部 API 的钱。

## 一、看（不用点任何按钮）

1. 打开 `#/script-create?new=1`，面板顶部的**剧目下拉**默认选中 `series10_s2`（第二季）。
2. **整季表**：每集一行，列为 集 / 结论 / 分数 / 失败项 / 花费；表头写“整季花费 $5.62 / $8”。
   - 结论的意思：`awaiting_writer` 在等写手交稿；`awaiting_reviewer` 在等评审；`importable` 已过导入闸门；`not_importable` 还有失败项。
   - 现在应该看到：ep01 `importable`；ep02 `awaiting_writer`（失败项 1）；ep06 `awaiting_writer`（在写大纲）；其余集是之前的状态。
3. 点某一集，下面的**各段一行**：每段有一个状态点、段名（Brief / 故事线 / 分集大纲 / 单集剧本 / 分镜 / 事实表 / 代码判定 + 补丁 / 打分 / 导入决定 / 导入闸门 / 导入）、谁来判（code = 代码；api_model = 写作 / 评审 agent；owner = 你），以及花费。
4. **代码判定 + 补丁**这一段默认展开，逐条列出没过的条目（例：ep02 只剩“镜4：动机光源‘顶灯’在本镜画面 / 场景里没出现”）。
5. 面板最下面是**分数轨迹**（测试期显示“代码判定满足条数 / 27”）。

## 二、点（方便时再做）

6. **一键返修**：选一集，点“一键返修”。几秒后这一集的结论会变成 `awaiting_writer`（或 `awaiting_reviewer`），说明系统已经出了新的写作 / 评审任务包；写手交稿后，结论会自动往前走（自动推进由编排器每 60 秒检查一次）。
7. **一键导入**：只有结论是 `importable` 的集按钮才亮。第二季现在会置灰，旁边写“第二季导入目标待 WORKFLOW / PRODUCER 接 --run”——这是预期的，不是故障；等导入目标接好后才能点。

## 三、哪些情况算没通过

- 面板显示“接口还没上线”或整季表是空的；
- 整季表的花费和上面的数字对不上；
- 点“一键返修”后结论 1 分钟内没有变化；
- 置灰的“一键导入”可以点。
