# ep01《量尺》首尾帧设想（L-203）

- 写于 11-06 08:3x JST｜作者 FRAMEPAIR（导演 / 分镜）｜依据 L-192 / L-200 / L-201 / L-203
- 来源分镜：data/pipeline/runs/series10_v2/staging/P4_ep01.L3_psm8.md（16 镜，故事、对白、时长、人物、造型、场景一律不动）
- 目的：每镜画两格分镜——起幅 = 铺垫，落幅 = 本镜的落点。两格至少两项明显不同（景别 / 机位角度 / 人物位置或姿态 / 关键动作完成 / 道具状态 / 光线），变化只来自本镜的运镜与动作，5–6 秒内做得到。尾帧按落幅单独构图出图，不再拿首帧小改。
- 通用约束：焦段三档 28 / 50 / 85（L-192）；轴线 卓琳左—祁念中—唐瑶右，江予白右前景面朝左，整集不越轴；没有人看镜头、没有正面排排站（L-200）；两人以上一律前后错落、身体斜 45°；现实段冷灰顶光（4000K，黑旗负补），幻想段环形灯暖金（镜2–镜3），切换靠环形灯的亮 / 灭写进前后两镜的画面（L-201 ③）。
- 标记：“（改运镜）”= 幅度或运镜类型与分镜不同；“（改末拍）”= 为了让落幅成立调整了最后一拍的动作，剧情与对白不变。

## 镜1（5 秒，push_in 中幅（改运镜：小→中））
**存在的理由**：开场钩子——一句“站好，肩挨肩”，两个人的肩被命令贴到一起；末拍环形灯亮，现实被推进幻想。
**背景视向**：sk_white_cyc（白幕正面（A 区主镜头））

**起幅**
- 景别｜机位：中景｜A 区侧 45°、1.4 m 平视略低｜50mm T2
- 构图：唐瑶右前景侧身略虚；祁念正中 3/4 转向右前在焦点上；卓琳左后排一步之外侧脸在焦点上；三人三层深度，右前景一角是关着的环形灯架、暗色金属环
- 人物姿态：卓琳右手刚把软尺甩直，尺带绷成一条直线横在画左、尺头扣在红指甲里，嘴张开在说“站好”；祁念与唐瑶的肩之间还有一掌宽的空隙，祁念视线落在暗灯圈上、嘴抿着；唐瑶看地面
- 道具：软尺绷直；灯圈暗
- 光线：顶灯冷白只勾三人肩线与发顶，白幕中灰渐变，远处造型灯暖点在焦外

**落幅**
- 景别｜机位：中景偏紧（推进一档，三人的肩线占到画幅中段，卓琳仍在画内）｜同机位同高度｜50mm
- 构图：祁念和唐瑶挨上的两个肩膀在画面中部成一条连线，卓琳的侧脸在左后压在这条线上方；右前景的灯圈从暗环变成一圈亮环
- 人物姿态：祁念的肩已贴上唐瑶的肩、没有缝隙，她抬眼、下巴抬起看向刚亮的灯圈，嘴唇微张；唐瑶肩膀被碰到、睫毛垂着；卓琳嘴唇合上，侧脸被闪光打亮
- 道具：软尺垂落在卓琳手侧、不再绷直；灯圈亮
- 光线：环形灯啪地亮起，暖白光从右前方闪满画面、略过曝，三人右侧的脸和肩被打亮，冷灰只剩画左一角

**变化项**：① 景别 中→中紧（推近驱动）② 人物位置 两人肩隔一掌→贴上（动作）③ 道具 软尺绷直→垂落（动作完成）④ 光线 冷灰→暖白闪（环形灯亮）
**剪接**：光闪匹配切——落幅的光闪就是镜2 的第一帧余晖；祁念的视线方向（右前上）接镜2 的灯圈，不越轴。

## 镜2（6 秒，bolt_push_settle 中幅）
**存在的理由**：幻想段登场爆点——灯一亮、风一起，她变成灯下唯一的主体。
**背景视向**：sk_white_cyc（白幕正面（与镜1 光闪配对、同视向））

**起幅**
- 景别｜机位：中景｜祁念右前 45°（环形灯一侧）、1.3 m 低机位微仰｜50mm T2
- 构图：祁念侧前 45° 入画、在画面正中偏上；灯圈一角在右侧、光闪余晖从右前晕进来；唐瑶背影的右肩占右下前景、灯圈外的暗里
- 人物姿态：祁念下巴还平着，长发贴在肩后没有动，左手刚搭上亚克力椅背；视线钉在灯圈上，嘴微张
- 道具：风机刚启动、发丝未扬；灯圈亮
- 光线：光闪余晖、画面略过曝，暖金尚未稳定

**落幅**
- 景别｜机位：中近景｜机位已急推到祁念正面偏右、锁定，仍 1.3 m 微仰｜50mm
- 构图：祁念的脸与抬起的下巴居中，扬起的雾蓝发丝占画面上部三分之一；唐瑶只剩右下角一片暗色虚焦；白幕在她身后最亮、向四周渐柔
- 人物姿态：下巴抬起、肩线向后展开，碎刘海从眼前扬开，胸口刚起伏完一次；灯环的亮点落在瞳孔里；嘴唇合上、嘴角牵起一点
- 道具：发丝扬到最高点；左手撑椅背
- 光线：暖金高调、曝光落回正常，光比 3:1 以内

**变化项**：① 景别 中→中近（急推驱动）② 机位角度 侧前 45°→正面偏右（bolt 弧线急推）③ 姿态 发贴肩、下巴平→发丝扬到最高、下巴抬起（风机 + 表演）④ 光线 过曝余晖→稳定暖金
**剪接**：视线匹配切——她钉着灯圈的视线（画右前）接镜3 灯圈另一侧举相机的江予白（画右三分之一、面朝左）。

## 镜3（6 秒，push_in 小幅）（改末拍）
**存在的理由**：快门密集到停住——他第一次从取景器后面抬起眼睛看她；灯灭，幻想结束。
**背景视向**：sk_white_cyc_rev（相机位反打侧：江予白身后的柔光箱灯架、监视器推车冷蓝屏、桁架、远处带小窗的门）

**起幅**
- 景别｜机位：近景｜B 区侧 45°、1.6 m 眼平｜85mm T1.4
- 构图：江予白在画右三分之一，相机贴在右眼前占右下，左肘撑灯架横杆；白幕在左后虚成明亮暖白；右后监视器冷蓝与造型灯暖点成光斑
- 人物姿态：食指正在连按快门，右眼贴取景器、嘴唇抿着；右手腕的黑色相机皮带垂下一截
- 道具：相机在眼前；环形灯亮
- 光线：环形灯暖金从身前偏左 45° 打亮指节、相机顶盖与半边脸

**落幅**
- 景别｜机位：近景略紧（眼睛与放低的相机顶盖同框）｜同机位｜85mm
- 构图：相机放低到下巴以下、顶盖在画面下缘，露出他整张脸，眼睛在上三分之一偏右；左后白幕从暖白落成中灰
- 人物姿态：快门停了，视线越过相机顶盖落在画左白幕方向，眼睑抬起、嘴唇微张；拇指停在背屏上
- 道具：相机放低半寸以上、不再贴眼；环形灯刚灭、灯圈变暗环
- 光线：环形灯啪地灭，暖金从他半边脸上消失，只剩顶灯冷白落在鼻梁与相机顶盖，画面落回冷灰

**变化项**：① 道具 相机贴眼→放低露脸（动作完成）② 光线 暖金→冷灰（环形灯灭，现实↔幻想触发画面写进本镜）③ 景别 近→近紧（推近）④ 表情 抿唇按快门→张口抬眼
**改末拍说明**：分镜 4–6 秒写“眼睛贴回取景器”，这样落幅会和起幅一样；改为相机留在胸前、眼睛看白幕、灯灭入画。对白无、剧情不变，符合 L-201 ③“切换前后两镜都写触发画面”。
**剪接**：声音匹配切（快门停 + 灯灭的继电器声）——冷灰接镜4 的冷灰；他看向画左的视线接镜4 被量的祁念。

**剪接**：动作匹配切——卓琳的肩直起、软尺收回，接镜5 同机位：她的肩重新压回蹲姿、软尺勒上唐瑶的腰（镜5 起幅）。

**背景视向**：sk_white_cyc（白幕正面（镜4 复刻对、同视向））

**起幅**
- 景别｜机位：中近景过肩｜镜4 同机位同焦段同高度 1.1 m｜85mm T1.4

- 人物姿态：卓琳后脑压向刻度；唐瑶视线落在身前地面、嘴闭着，右手自然垂在身侧（不在画内）
- 道具：软尺勒在唐瑶腰侧棉布上
- 光线：顶灯冷白勾唐瑶发顶与锁骨

**落幅**
- 景别｜机位：中近景过肩不变｜同机位｜85mm
- 构图：卓琳的后脑从左下抬起转向唐瑶的脸——前景色块升到左中、露出她侧脸的轮廓线（仍虚）；唐瑶的脸位置不变，但她的右手进入画面下缘、掐在腰侧
- 人物姿态：唐瑶下巴压低、嘴唇抿紧、睫毛垂得更低，右手指节掐着腰侧的缎面发白；卓琳嘴唇合上

**变化项**：① 道具 软尺勒腰→消失 ② 前景人物姿态 卓琳后脑压低→抬起转向唐瑶（前景色块位置变）③ 唐瑶姿态 手垂、下巴平→掐腰、下巴压低（固定机位，动作必须大而清楚）
**剪接**：动作匹配切——卓琳抬头站起、视线移向亚克力椅，接镜6 她把邀请卡拍在椅面的那一声。
