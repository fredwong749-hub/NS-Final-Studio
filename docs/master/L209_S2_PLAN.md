# L-209 S2 状态收口：改法（给项目方确认）

> 起草：PS-MASTER，2026-11-07 01:3x JST。依据：docs/master/ARCH_MAP_20261106.md（S0 现状全图）、docs/master/SHADOW_REPORT.md（S1 影子调度）、今晚的事故记录（CHANNEL 11-05/06）。
> S2 只做“状态收口”，不换派单（换派单是 S3）。生产不停，每一小步都单独发版、独立复审、影子对比验收，不达标就回退。

## 为什么先做 S2

今晚查出的事故，大半不是“哪行代码写错”，而是**同一件事存了好几份、各自算**：

| 现象（今晚真实发生） | 结构原因 |
|---|---|
| ep01 已在 gpu36 出完的 5 镜视频，gpu33 一直显示“等编排器”，被当成卡死 | 每台各有一份视频状态，孤儿记录不清 |
| 两台对“当前集在哪个阶段”看法不同（gpu33 说视频段，gpu36 说首尾帧段） | 阶段每台各算一次 |
| 两份 partition.json 内容不同，producer 读一份、派单读另一份 | 同一配置两份副本 |
| ep01 一个例外，让 L-206/207 卡位规则整晚没生效 | 规则按每台的局部状态判断 |
| ep02 换了新分镜，旧分镜出的首帧照样往下出尾帧和视频 | 帧不记“出自哪版分镜 / 哪版规则” |
| 大脑把 ep02 显示成 0/16（实际 gpu36 已过 11 张） | 汇总时取错了副本 |
| 你点的“用这张”被判成“重复登记”拒掉 | 代选和你的选择写两条路，后写的被挡 |

这些修一个冒一个，根子是**没有唯一的真相**。S2 就是把真相收成一份。

## 目标形态（S2 结束时）

1. **一个状态主机：gpu33。** run 级状态只有一份，放在 gpu33：登记表、集阶段、分区、集关闭标记、闸门与重打分结论。gpu36 和笔记本只读它的副本，不自己算。
2. **每个产物带签名。** 每张首帧、尾帧、每段视频都记下：出自哪版分镜（剧本输入签名）、哪版提示词、哪版规则（契约 / 看图 / 卡位）。签名不符的当前版自动换代（不计次），不再靠人发现。
3. **集关闭标记。** 合成完的集打上“已关闭”，所有执行器（出图 / 视频 / 打分）都不再给它派活，除非你重新打开。
4. **一张卡位表。** hosts.json 是唯一来源；producer.py、night.py 里写死的卡表全部改成读它。
5. **“为什么没派”有记录。** 每张空卡、每个等待中的镜头都能说出原因（等资产 / 等闸门 / 等打分 / 卡位规则），影子调度的“说不清原因”降到 0。

## 分 6 小步做（每步一个版本）

| 步 | 改什么 | 验收（影子调度 + 巡检自动核） | 回退 |
|---|---|---|---|
| S2.1 | **签名 + 自动换代**：每个 take 记 `script_sig / prompt_sha / rule_fp`；当前版签名不符 → 自动换代（不计次，旧版保留到新版过闸）。这条覆盖事故最多的一类（规则 / 分镜升级后旧产物不复验）。 | 改分镜 / 改规则后 10 分钟内，受影响的镜全部进入换代；不受影响的镜一个都不动 | 配置开关一键关 |
| S2.2 | **集关闭标记**：合成成功 = 关闭；执行器读标记跳过；你可以在网页“重新打开”。 | 关闭的集 0 次派单；ep01 视频不再占 ep02 的出图卡 | 开关关 |
| S2.3 | **partition 只留一份**（data/state 那份为准；config/netfix 那份隔离不删）；临时 hold 带到期时间。 | 两台、笔记本读到的分区 md5 一致；没有超过 2 小时的临时 hold | 恢复旧文件 |
| S2.4 | **集阶段只算一次**：gpu33 算、写进状态主机；gpu36 的 night / producer 只读。 | 影子调度“两台阶段不一致”= 0 | 退回每台自算 |
| S2.5 | **登记表收成一份**：gpu33 汇总两台的结果写主登记表；每台本地的变成只读缓存；大脑、网页、KPI 都读主登记表。孤儿记录在汇总时清掉。 | 两台登记表差异 = 0；孤儿 = 0；网页 / 大脑 / KPI 数字一致 | 退回各读各的 |
| S2.6 | **一张卡位表 + “为什么没派”事件**：去掉写死的卡表；producer / asset_worker / vidgen 每拍写“空卡原因”；资产作业上报占卡。 | 影子调度 `unexplained` = 0；卡位表只有 hosts.json 一处 | 退回写死表 |

顺序理由：S2.1 和 S2.2 立刻减少返工和占卡，收益最大、风险最小，先做；S2.3–S2.5 动数据流，影子调度先跑通再切；S2.6 收尾，为 S3（唯一调度器接管派单）铺路。

## 不在 S2 里做的（留给 S3 / S4）

- 撤掉静态分区、由一个调度器给 6 张卡统一派单（今晚空卡的最大来源）——S3。
- 笔记本退出关键路径（隧道、relay、拉取）——S4。
- 删除旧文件（14 个 .bak、旧登记表）：S2 结束后列清单给你批，批了才删。

## 风险与保护

- 每一步都有开关，默认先“只记录”跑一段，由影子调度核对，没问题再“生效”。
- 状态主机放 gpu33：gpu33 掉线时，gpu36 按最后一份副本继续跑当前集（降级为只读不收新决定），并告警；不会两台各写各的。
- 不碰 gpu33:2；不动功耗；不自动删任何东西；成人镜规则（L-128 / L-210）不变。

## 时间

每一小步约 1–3 小时（编码 + 单测 + 独立复审 + 发版 + 影子验收）。6 步合计约 1–1.5 天，生产不停。
