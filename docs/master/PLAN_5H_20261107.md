4. **每镜一个“重做”按钮**：点了直接重出，不确认、不来回。
5. **分支干净 + 每版自动上传**：和另一个团队协作；每版发完自动合并、推 master 和 nsfinalstudio；已合并的 release 分支清掉；分支规范写清楚。
6. **审查机制**：每版发版前独立复审 + 端到端验收必过；不再“写一堆垃圾进去”。
7. **GPU 调度要聪明、不卡**：S3 唯一调度器（影子先证明比现在好）。
8. **系统自己发现问题**：自查每 3 分钟（已上线），发现即派修。
9. **效率可度量**：记分卡（单集分钟、首帧一次通过率、空卡率、项目方撞到的 bug 数、token 花费）。
