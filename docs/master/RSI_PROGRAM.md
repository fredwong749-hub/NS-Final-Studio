# 五条 RSI 线：标准、分数、目标（总调度 fredw-2b，11-02 03:5x，L-112）

> 项目方原话（11-02 03:5x）：“我需要你再做一个 image 生图的 RSI……模型参数一致性调研……镜头提示词学习……灯光提示词整理与学习（人物跟背景混合时怎么把灯光做得更好、更加柔和；科学的打光）……两条重要 RSI 线：做图的线、做视频的线（MiniMax / 现在用的 Pika Flex）……剧本与分镜转化：给你一个提纲，怎么转成镜头剧本，再转成分镜……UI 的 RSI……系统代码的 RSI：怎么让这个系统把规则全部体现下来，在不用 Claude 的情况下依然能跑得很棒……记录与迭代……最终目标：一定要达到现在好莱坞电影的水平……镜头运动和人物表情也很死板，剧本的能力也没有写好……你自己把这些 RSI 的标准、目标和分数定好……全部的 RSI，我给你一整晚的时间。”

## 共同规则
- 每条线有自己的**分数（0–100）**，由代码按下表的指标自动算，写入 `data/rsi/scores.jsonl`（时间、线、分数、各分项、版本号）。SENTINEL 把分数轨迹画进 8810 看板，并在 `data/review_pages/rsi/index.html` 生成每晚报告。
- 每轮：量分 → 找最低分项 → 查根因（先找结构化方案，不加提示词句子了事，G0）→ 改系统 + 规则 + check（G1）→ 小样 A/B → 总调度亲审 → 上线 → 重新量分。分数不升不算完成。
- **好莱坞参照**：每条线都维护一份参照集（电影剧照 / 片段的公开截图，只本地存放、只给本地模型看），用同一套指标给参照打分，作为满分锚点；我们的分数按“占参照的百分比”换算。
- 项目方定过的决定不推翻（S★ R0 观感、全 Pika、演员不看镜头、成年自愿虚构等，见 MASTER_PICTURE）。
