## 三、资产隔离规则（这次重做的根本原因）
1. V2 的每一个参考资产都登记在 V2 资产包清单里（assets_v2/manifest.json：角色 → 身份脸 / 每套造型的设定图 / 单品；场景 → 底图），每项都带 sha。编译只许从这份清单取参考，读到清单外的文件就在 preflight 挡住。
2. 一个事实只有一个来源：身份脸只经 asset_refs.face_of(series10_v2, cid)，读这份清单；设定图、场景底图同理。V1 的 face_overrides、refboards、refcrops 一律不继承。V2 不设 inherits，这一点和第二季继承第一季不同。
3. 派生参考图（refcrops / refboards）只在笔记本按资产包生成一次，按 sha 推到两台；服务器编译时不许在本地重新生成（FACTORY 18:1x 发现 gpu36 本地重生成会导致字节不同）。
4. 资产包锁定后，改任何一项都要项目方点选，换版自动列出受影响的镜头（L-117 的原子写）。
5. 林晚身份脸：沿用 L-122（ar-c2351c9dcf）作为 V2 的身份锚点（项目方 18:3x 点选“沿用今天定的这张”）。新设定图都围绕它生成。
