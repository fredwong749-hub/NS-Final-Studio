## 一、一次做对的方法：先走一镜，再走一集，最后铺开

今天所有返工的共同原因，是“规则改一半就全量开跑”。V2 不这么做：
1. **金样镜（golden shots）**：从 V2 ep01 里挑 3 镜（单人特写、双人中景、背影或远景各 1），先走完全部 9 步，每步都由总调度亲审。任何一步不过，就修代码或规则，重走这 3 镜，直到 3 镜一次全过。
2. **金样集**：ep01 整集走完 S1–S9，项目方看整集预览。这一集的通过率、返工数、同类反馈数就是放量的门槛（见第五节）。
3. **放量**：ep02 → ep10 按集顺序（L-124），能并行的阶段重叠进行。
4. 在金样镜和金样集通过之前，不批量出图，避免一错错一片。
