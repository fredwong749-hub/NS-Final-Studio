## 三、通用参数模板
- 基础参数：焦段（24mm 广角 / 35mm 标准 / 50mm 特写）、光圈（T1.4–T2.8）、帧率（24/60/240fps）、镜头（Zeiss/Cooke/K35）、风格（电影质感/低饱和/暖冷对比）
- 约束条件：人物面部稳定、无穿模卡顿、无水印 BGM、禁止分身

## 四、避坑技巧
- 避免重复“环绕+推拉”冲突，用“匀速”“无抖动”稳定画面
- 慢镜头加“无渐变过渡”，甩镜强调“运动模糊+瞬间清晰”
- 复杂运动拆成简单动作（如“先推近再环绕”）

## 五、完整示例（原文，可灵/Runway 直接用）
- 甩镜+环绕：老厂房外，35mm Zeiss，起幅侧脸眨眼→极快甩镜（运动模糊）→落幅镜中正面，肩膀微沉；匀速环绕，背景光带，变形宽银幕，高清细节，面部稳定，无水印 BGM
- 焦点转移：室内，35mm T1.4，机位固定，焦点从翻倒玻璃杯切到阴影中女人，暖台灯+冷环境，低饱和，无穿模
- 慢镜头：拳头砸水，240fps 慢放，水珠悬停，暖侧光勾轮廓，青灰蓝阴影，背景音保留
- 变速推近：车厢，50mm Cooke，三段速度推近，骤停时抬头，暖顶光压暗背景
- 上升环绕：枯草地，摇臂螺旋轨迹，仰拍抱臂→升高俯角，夕光风拂发，电影质感
- 细节到全景：信特写→摇臂后退拉远至书房全景，暖台灯+青灰蓝散焦
- 前景遮挡：铁栅栏前，40mm T1.4，焦点锁女人，逆光质感
- 主观移动：穿越机超低空穿货架，跟跑回头，运动模糊
- 升降：摇臂升起，从仰拍抱臂到俯角全景
- 手持：奔跑时自然抖动，纪录片风格
- 变焦：固定机位，极速变焦定格表情
- 横移：侧跟奔跑，Steadicam 平滑
- 固定：人物站定，35mm T1.4，无抖动
