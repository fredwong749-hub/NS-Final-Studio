# 图像编辑器 · 给 UI/UX 设计 agent 的 brief（IMGEDIT-RESEARCH，2026-11-02）

> 依据：docs/research/imgedit/DEEP_RESEARCH.md（下文写“B10-n”“E-n”“A1-4”，指那份文件的条目）。产品方向沿用 ASSETUX R3（data/review_pages/assetux/path.html）：一个入口“修改”、一个右侧抽屉、版本带、只有正向动作（L-123）、不说技术话、不放灰按钮。本 brief 只补**人物修改**和**场景修改**两条主路径的每一步细节，不推翻已定的方向。
> 项目方原话：“这个东西主要是为了人物和场景的修改来做的”；“这个页面我不接受，非常糟糕。”

## 0. 硬约束（来自项目规矩，设计时逐条对照）

- **不许静默删功能。** 现行 ImageEditPage 的功能必须在新设计里找到去处，见 §4 旧功能清单。
- **只有正向动作。** 每张图只有“用这张”“修改”和“⋯”三个动作，没有“不要”（L-123）。
- **条件不满足时按钮直接不出现。** 该出现进度的地方显示进度，不写条件说明，不出现 P1、takes、sv-11、parent 这类技术词。
- **点选即生效。** 不让项目方打字确认；需要拍板时用选择题。
- **提示词改写只走外部写作 API。** 界面显示“它理解的改动”。改写失败时不出图，并用大白话说明原因。
- **图片不出本机。** 发给外部的只有文字。
- 桌面 1440 和 1920 宽两档，都要截图自查。

## 1. 公共骨架（两条路径共用）

| 区域 | 内容 | 依据 |
|---|---|---|
| 左：大图台 | 底图或选中的版本；选区和标注画在上面；“对比”开关打开后是左右滑杆（左 = 当前，右 = 选中） | ASSETUX；滑杆对比是我们自己的增量，竞品里没查到（B9） |
| 顶：工具条 | 整张 · 点选主体 · 画笔 · 框选 · 恢复笔 · 反选 · 标注笔（箭头、圈）· 撤销 / 重做 | B10-1/2/3/4/7；ChatGPT 的 Undo/Redo |
| 右：操作栏 | ① 快捷动作卡 → ② 一句话输入框 + 建议 chip → ③“它理解的改动” → ④ 参考图（带角标和角色）→ ⑤ 出几张 + 生成 → ⑥ 高级（折叠） | B10-16/17/5/6 |
| 底：版本带 | v0 = 底图；每次生成追加一组；生成中的格子显示呼吸灯、“排队第 N”、预计时间；选中后可“再来几张相似的”或“以这张为底继续改” | ASSETUX；B10-9/18/19 |
| 右上 | 从镜头打开时是“采用到这一镜”，从资产打开时是“采用为资产”；功能没上线就不显示 | ASSETUX；L-117 |

**交互细节（每条都要落到设计稿上）**

1. **选区语义。** 不选区就是整张改；选了区就只改选区，框外像素由系统贴回原图来保证。不要在界面上解释这条，只在选区外加一层淡灰。
   - 依据：ChatGPT 官方提醒 “edits may extend beyond the area you selected”（B3），所以要靠合成保证。
2. **点选主体（P2，P1 先用画笔和框）。** 悬停时高亮人物、衣服、手、桌子；点一下选中，Shift 加选，Alt 减选。依据：B10-2。
3. **恢复笔。** 把某块涂回原图，常用于“改衣服时脸被带动了”。依据：B10-4。
4. **标注笔。** 在图上画箭头或圈，系统自动给每个标注分配一种颜色。提示词里自动写成“红圈内…”，项目方看到的是“红圈：右手”。依据：A1-4 和 docs.comfy.org 的“点出标注颜色就能指向区域”。
5. **一块区域一句话（P2）。** 每个选区或标注旁边出现一个小输入框，就近写这块要怎么改。依据：B10-8。
6. **参考图角标。** 底图固定是角标 1，标“要修改的图”。其余参考图按顺序是 2、3、4，每张带角色下拉：人物长相 / 服装 / 单品 / 场景 / 姿势骨架 / 光线参考。默认带哪几张由系统按本镜或本资产编译好；可以拖入、替换、去掉勾选。依据：B10-5/6；E-5。
7. **提示词助手。**
   - 项目方在大输入框里写口语（5 行起，随内容长高）。
   - 点“生成”后先显示“它理解的改动”，分三行：改什么 / 保留什么 / 分几步（E-17）。
   - 英文提示词默认折叠，展开后可以手改；手改的内容记账。
   - 一句话里有 ≥3 处改动时，弹一个选择题：“分 3 步做（更稳）/ 一次做完”（E-7）。
   - 依据：B10-17；Ideogram 的“想逐字遵循就关掉扩写”。
8. **建议 chip 按当前路径变化。** 人物路径和场景路径各一套，点一下就加进输入框，见 §2、§3。
9. **生成中的反馈。** 版本带里的格子先占位：呼吸灯、“排队第 N / 出图中 / 质检中”、预计几点几分（frame_edit_queue 已经能给 ETA）。关掉抽屉后，卡片和右下任务条照样显示进度。
10. **结果卡片。** 显示缩略图、序号，以及一个质检小点（过 / 没过）。点开后在大图台上显示，质检原因点小点才展开。没过质检的版本照样可以“仍然用这张”，记审计（EDITOR_INTEGRATION A7）。
11. **多轮提醒。** 在修改版上继续改到第 5 次时，版本带上方出现一条：“已经在修改版上连改 5 次，画面可能变糊。从 v0 重开？[从 v0 重开] [继续]”。依据：E-18，A1-5 第 3 条。
12. **换模型重做。** “⋯”菜单里放“用另一个模型再做这张”，模型名只在高级里显示。依据：B10-10。
13. **快捷键。** Esc 关闭，Enter 生成，Ctrl+Z / Ctrl+Shift+Z 撤销和重做，1–4 切版本，[ ] 调笔刷大小，A 用这张，E 修改，C 对比。

## 2. 主路径一：人物修改（换装、脸更像、改姿势、修手、改表情和妆容）

| 步 | 界面 | 交互 | 提示词处理（系统做，项目方看不到细节） |
|---|---|---|---|
| 1 进入 | 镜头首帧或尾帧、资产卡（设定图、身份脸）、待你看里的图，点“修改” | 右侧抽屉滑出，底图 = 当前版本 | 从编译结果带入：人物、造型字段、参考槽（身份脸 > 设定图 > 单品）、景别 |
| 2 选做什么 | 操作栏顶部一排**快捷动作卡**：换衣服 / 换鞋和单品 / 脸更像 / 修手 / 改姿势 / 改表情 / 更写实的皮肤 / 自由修改 | 点卡片后自动切到合适的选区工具（修手 → 画笔并放大到手部；改姿势 → 弹出姿势骨架选择；换衣服 → 点选衣服）。不点卡片也可以直接写 | 卡片决定任务类型（E-1）和推荐模型（F1）：换装 → Qwen 2.1（画布 = 人物图）；改姿势 → 2511 + 骨架图；修手 → 区域编辑 + crop & stitch |
| 3 选范围 | 工具条：画笔、框选、点选主体、恢复笔 | 修手、改脸默认要求有选区；换装可以选衣服，也可以整张 | 选区转成 mask（走 mask 支路）或颜色标注（走标注支路）；坐标转成位置词（“右手”“上衣”）交给改写器（E-6、E-12） |
| 4 给参考 | 参考图区：角标 2 = 人物长相（身份脸，默认已带）；换装时多一格“服装”，可以从衣橱缩略图条拖入单品 | 拖入后自动标上角色，可以改；改姿势时出现“姿势骨架”格，从 pose 模板库里选一个（tools/imglab/pose_templates.py 已有） | `<image1>` = 底图，`<image2>` = 身份脸，`<image3>` = 服装……；提示词按角色写（E-5、E-9）；身份**指向参考图**，不用文字描写五官 |
| 5 说一句话 | 大输入框，下面是人物 chip：脸更像她 / 鞋换成… / 手放到桌上 / 表情更轻一点 / 皮肤更真实 / 领口更挺 | 点 chip 加进输入框；可以 @ 衣橱单品 | 外部写作 API（edit_prompt_rewrite.md，按目标模型选模板 E-0）+ 本地 VL caption（文字）作输入；规则：只改点名的属性并改到位（E-2）、保留用一句总括（E-3，待 A/B）、表情和妆容轻微（E-8）、多处改动逐条列（E-7） |
| 6 看理解 | “它理解的改动”三行；英文折叠 | 不对就直接改那句话再点生成；≥3 处改动时弹“分步 / 一次”选择题 | 改写失败时不出图，原因用大白话写在同一位置 |
| 7 生成 | “生成 3 张”按钮 + 预计时间 | 版本带追加 3 格占位 | 身份闸门：Q1 锚分 ≥ 原版 − 0.03；没过的照样展示，小点标红 |
| 8 比较 | 大图台 + 对比滑杆；选区处高亮 | 1–4 切换；在满意的那张上点“再来几张相似的” | “再来几张相似的” = 同一提示词换 seed，以这张的 seed 邻域为参考 |
| 9 继续改或采用 | 选中的版本：用这张 / 以这张为底继续改 | “用这张”是原子写；身份脸、设定图要先弹“会影响 N 个镜头”，再勾选要重出的镜 | 采用后自动写一条学习记录（原图对修后、选区、类型、那句话） |

## 3. 主路径二：场景修改（光线、陈设、换背景、时间段、清理杂物、扩图）

| 步 | 界面 | 交互 | 提示词处理 |
|---|---|---|---|
| 1 进入 | 场景底图卡、镜头首帧（想改的是背景时） | 同一个抽屉 | 带入场景名和描述、镜头视角 |
| 2 选做什么 | 场景快捷卡：改光线 / 换时间段（白天、黄昏、夜）/ 换背景（保人）/ 加或换道具 / 清掉杂物 / 扩图 / 自由修改 | 改光线 → 在图上摆光源（拖动光源点，选暖、冷、柔、硬四种，P2）；换背景 → 自动反选人物（保人换景）；扩图 → 1.5x / 2x 按钮 | 改光线写成光源、方向和明暗变化（E-14）；换背景先锁主体（E-13）；扩图用固定模板 “Extend the image beyond its boundaries using outpainting. The original caption is: ”（C1-a） |
| 3 选范围 | 框选、画笔、反选；“清掉杂物”用画笔涂 | 镜头首帧里换背景时，人物自动被保护（选区外 = 人物） | 结果用人物 mask 贴回原人物像素（F1“换背景”） |
| 4 给参考 | 角标 2 = 场景参考（场景库里的图），角标 3 = 光线参考（可选） | 拖入或从场景库选 | 写明“`<image2>` 提供场景布局”“`<image3>` 只提供光线色调” |
| 5 说一句话 | 场景 chip：窗光从左边来 / 换成黄昏 / 桌上加一束花 / 背景再虚一点 / 去掉墙上的字 | 同人物路径 | regen_prompt_rewrite.md 的场景段：视角和空间结构保持不变；“无人物、无文字”写成正向描述（E-10），不再靠 negative_add |
| 6–9 | 同人物路径 | 采用场景底图前先弹“影响 N 个镜头” | 同人物路径 |

## 4. 现行 ImageEditPage 旧功能清单与去向（不许静默删）

| 旧功能 | 去向 |
|---|---|
| 基座列表（Qwen 2.1 / Klein / MOSS）及就绪状态 | 收进“高级 ▸ 模型”；没接通的不显示；“⋯ → 用另一个模型再做” |
| 张数 1 / 2 / 4 | 生成按钮旁的“出几张”（1–4） |
| 种子 + 锁定 | 高级里；“再来几张相似的”覆盖常见用途 |
| 预设显示（S★ R0） | 高级里只读显示 |
| 只读编译提示词 | 变成“它理解的改动”和可展开的英文提示词（可手改）；原编译提示词在“⋯ → 查看这一镜的出图提示词” |
| A/B 并排（Shift + 点） | 对比滑杆，外加“并排”切换 |
| ★ 设为候选 | 版本带上的“用这张”（采用接口上线前，用这张 = 标为本镜首选候选） |
| 参考图 tab | 操作栏的参考图区（带角标和角色、可拖入） |
| 质检 tab | 结果卡上的质检小点，点开看原因 |
| 元数据 tab | “⋯ → 详情”（种子、用时、模型、提示词、复制复现参数，参照 BFL 的 API Code） |
| 版本树 tab | 版本带（线性链，可回到任意一版）；分支图放 P2 |
| 出图历史片条（工坊 + 本镜） | 版本带（按时间，工坊出的和本镜的合在一起，用小标区分来源） |
| 镜头号输入框 | 删掉：从入口带上下文打开；页面直达时显示“从镜头或资产里点修改进入”，并列出最近编辑过的 5 个对象 |
| 采用到镜头 / 采用为资产（灰按钮 + 解释） | 接口上线前不显示（L-123 不放灰按钮） |

4. 交付时附旧功能清单逐项对照表（§4），以及 1440 和 1920 宽的截图。
