## 结论（置信度：高，代码 + 提示词逐字对照）

顾沉长出林晚的蓝色长直发、水晶甲，**主因不在模型，在编译层**：

1. 剧本原文主语清楚：“林晚跪坐在深色木地板上，…雾霾天蓝色及腰直发齐刘海，…右手抬起接纸，5厘米超长透明水晶甲压住纸角；顾沉站在画面右侧，白衬衫袖口卷起，左手把一页…纸递到她面前”。
2. 脸部特写时 `framing.strip_fullbody()`（K-REN-123）按逗号切句，删掉含“跪坐 / 站在”的分句——**这两句正好是带主语名字的句子**。删完后正文变成无主语：“特写，平视，雾霾天蓝色及腰直发齐刘海，…右手抬起接纸，5厘米超长透明水晶甲压住纸角，白衬衫袖口卷起，左手把…”。
3. 编译顺序是 `景别句 → 【林晚】锁 → 【顾沉】锁 → 正文`，无主语正文紧跟在【顾沉】锁后面，于是“蓝色及腰直发、水晶甲”在文本上就归给了顾沉。模型照字面画。
4. 同类删句还有 `filter_parts()`（按景别删看不见的部件，K-REN-101/707）：删掉“林晚穿黑色漆皮短裙与…”这种以名字开头的穿着句，也会把主语一起删掉。

**全量扫描（102 镜）**：16 镜正文丢了主语名字（ep01-S1、ep02-S9、ep05-S1/S2、ep06-S1/S2/S6/S9、ep07-S4/S7/S11/S12、ep08-S1/S2/S5/S6）。
最危险的是 ep08-S5 / S6：删掉“顾沉穿白衬衫…”后，“黑色短发向后梳齐，从林晚肩后伸手”——**黑色短发在文本上归给了林晚**。
