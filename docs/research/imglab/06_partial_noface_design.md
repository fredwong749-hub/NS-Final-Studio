# 不露脸 / 局部镜出整张脸（ep05-S3 / S6 / S7，82 版无限重出）：根因与结构化方案（IMGLAB，11-02 08:0x）

> 证据：按生产路径编译（tools/pipeline/image_jobs.frame_prompt_full，sv-05 代码）的现行提示词，逐字摘录。三镜的 cast 都是“林晚（局部｜肩头 / 下颌与肩颈）、阿岚（局部｜手）”，faced_people = []。

## 根因：编译出的提示词里有 5 处在要一张脸（不是模型不听话）

| # | 提示词里的原文 | 来源 | 为什么会出脸 |
|---|---|---|---|
| R1 | “近景构图（胸部以上）” | framing.lead(近景)：剧本写的是“近景（手与肩颈）”，`closeup_subject` 只对特写类判主体，近景一律走人像首句 | “胸部以上”就是半身人像构图，画框里本来就有头 |
| R2 | “林晚的视线落在阿岚的脸上……阿岚的视线落在林晚的脸上” | frame_job.eyeline_note：按 sr.characters 逐人补视线句，**局部 / 不露脸的人也补**，落点还是“对方的脸” | 两个人都要“看对方的脸”，模型只能画两张脸 |
| R3 | “面部清晰对焦，五官锐利” | 场景段 / 纠正器通用句；只对 subject ∈ {part, object} 跳过（FACE_TERM_RE），近景不跳 | 直接要求画面里有清晰的五官 |
| R4 | “【林晚】22岁中国成年女性，蓝发及腰”“【阿岚】26岁成年女性” | framing.part_lock：局部到了肩 / 颈就保留发色句（W5 b），成年句永远保留（HC-07） | 年龄 + 国籍 + 性别 + 发型，等于一个完整的人物描述 |
| R5 | “林晚只露出肩头，不露脸” | framing.partial_clause | 本身没错，但 cfg=1 下否定词基本不生效（BAKEOFF R11-12 A3），还把“脸”这个字写进了提示词 |

另有剧本侧问题：ep05-S7 写了“林晚的下颌入画……睫毛压低看向那点金属”。睫毛属于脸，和 cast 里的“下颌与肩颈、不露脸”矛盾，属于写作格式问题。

## 方案 A：编译层（根治，sv-06 之后合入；K-REN-903，开关 image_framing.json partial_only）

触发条件：在画的人全部是局部（faced_people 为空，partial 不为空），或者某个人是局部（逐人处理）。

1. **首句**：不按剧本景别词出人像首句，改用局部特写写法（复用 `closeup_lead(size, "part", …)` 的肯定句式）：“{景别}构图：画面只到下颌以下，只拍{部位并集}这一局部，{部位}占画面大半（tight crop below the chin on the {part EN} only）”。部位取 cast 的 part 并集，比如“手与肩颈”。
2. **视线句**：`eyeline_note` 只给露脸的人补；局部的人不补。落点也不能写“X 的脸”，因为对方不露脸。
3. **脸部通用句**：`faced_people` 为空时，“面部清晰对焦，五官锐利”这一类（FACE_TERM_RE）不加。和 part / object 特写走同一条分支。
4. **角色锁**：局部的人只留可见部位句。成年句（HC-07）收窄为“成年女性 / 成年男性”，不带年龄数字和国籍；发色句只在部位包含“发 / 头”时保留。注意这会改动 W5 b 的规则，需要 IMGFIX 一起确认。
5. **否定句**：“只露出肩头，不露脸”改成肯定句“画面上沿在下颌以下”，和第 1 条合并。
6. **身份脸参考**：现行已经不挂（三镜的 refs 都是去头的设定图和参考板），保持。

验收（代码可算）：
- 三镜编译后，提示词不含“胸部以上”“五官”“面部”“的脸上”，也不含局部人物的年龄数字；
- 回归：tools/imglab/orphan_check.py 新增一项 `noface_terms`，对 faced_people 为空的镜，脸部词计数必须为 0；
- 出图后 postflight Q3 的“局部特写出了脸”项通过率作为指标。

## 方案 B：兜底（编译层修完还出脸时才用；A/B 只用非成人镜）

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| B1 裁切 | face_yolov8m 检出脸 → 画框上沿移到脸框下沿（下颌）以下 → 按 9:16 裁 → lanczos 放大回 768×1344 | 确定性强，不引入新内容 | 分辨率下降（裁掉 30% 就等于放大 1.4×），构图会变；手如果在脸附近会被裁掉 |
| B2 区域重绘 | 脸框外扩 → SetLatentNoiseMask / InpaintCrop，提示词写“头发 / 背景墙”，denoise 0.8 | 构图不变 | 可能长出新的脸或怪异的头部；会引入合成感 |

建议先上 B1。它只在 postflight 判定“局部特写出了脸”时触发，触发后再跑一遍 Q3 / Q5，过了才采用，否则照常换 seed 重出。A/B 镜头选 ep10-S1（陈宇局部｜手）、ep10-S9（林晚局部｜右手）、ep10-S3（陈宇局部），都是单镜判定非成人。

## 写作规则（交 HOLLYWOOD）

不露脸 / 局部的人，正文只写可见部位（手、甲、肩、发梢、衣料），不写睫毛、视线、唇、表情。lint 规则：cast 标为局部的人，正文同一分句里出现 FACE_WORDS 时阻断。
