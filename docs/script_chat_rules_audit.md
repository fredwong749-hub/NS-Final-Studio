# 剧本创作对话规则 · 对齐审计（script_chat_rules_audit）

> 日期：2026-10-30。审计对象：`config/script_chat_rules.md`（画布「剧本创作」对话框系统提示词第一部分）。审计后规则文件升为 `script_chat/v2`。
> 起因：项目方原话“ep01视频还是不行，我认为剧本没有按照minimax提示词规则以及image 2.1 turbo提示词写好”。
> 方法：逐个读来源原文，每条规则对照规则文件 v1 + 输出格式契约 `config/qwen_writer_system_prompt.txt`（契约已逐字拼进系统提示词，契约已写清的格式细节记“已覆盖”，不在规则文件里重复）。
> 状态含义：**已覆盖** = v1 规则文件或契约已写清；**缺失** = 两者都没写；**含糊** = 写了但不可执行（没说写什么、按什么顺序、什么字段、什么词不能用）；**冲突** = 来源之间互相矛盾（两边原文都列在第三节，规则文件按日期较新或项目方原话一方写并注明）；**不适用** = 系统 / 参数 / 后期规则，剧本写作者控制不了。
> 本文只写规则，不写任何剧情、画面、台词或提示词内容示例。规则文件中补写条文的位置用 “→ §x” 标出。
