负责：NAVIA。最后更新：11-02 18:xx。截图都在 `data/review_pages/navia/`（1280x800 与 1440x900 各一张）。设计稿：`data/review_pages/navia/index.html`。

## 1 顶栏分组（左：导航入口 · 中：页面 · 右：状态与个人）

| 区 | 内容 | 常驻 / 收起 | 说明 |
|---|---|---|---|
| 左 | logo（回画布）· ＋新建剧本 · ♪声音 | 常驻 | 声音和新建是创作动作，不是页面，放左 |
| 中 | **总览 · 剧本 · 资产 · 分镜 · 出图 · 视频 · 成片**（7 个，同层级同样式） | 常驻 | 顺序按工作流：先看全剧（总览），再 剧本→资产→分镜（每集一镜一行）→出图→视频→成片 |
| 右 | 待你看 · 反馈 · 系统状态 · 工具▾ · 主题 · ? | 前四个常驻；主题、? 在窄屏收进工具菜单 | 1280 宽度：主题、? 已收进“工具”（功能没删，工具菜单里有“界面”和“快捷键”） |
| 工具▾ | 写作对话、A/B、导入、资料清单、项目设置、模型与 API、任务队列、回收站、表格视图、分镜表、串播审片… | 收起 | 低频页面与运行工具 |

圆点（只用 灰 / 琥珀呼吸 / 琥珀实心 / 绿；优先级琥珀实心 > 琥珀呼吸 > 灰 > 绿）：
琥珀实心 = 要你看或卡住；琥珀呼吸 = 在出；灰 = 排队或没开始；绿 = 全部定稿。数字：出图、视频 = 已定稿/全剧镜数；剧本 = 集数；分镜 = 本集镜数；成片 = 本集版本数。窄屏数字只在当前页显示，其余在悬停里。

集选择器在顶栏已拿掉，下放为“页内范围条”（画布、成片、视频页；出图页自带集筛选）。“整集出片”改名“一键出片 · 第 N 集”，在范围条里。

## 2 页面关系图

```
顶栏 ──┬─ 总览 #/overview ── 单击格子：右侧详情 ── 双击：→ 分镜 #epNN-Sx
       ├─ 剧本 #/script-create ── 剧本库 / 新建 / 导入 ；工具：写作对话、A/B
       ├─ 资产 #/assets ── 人物 / 衣橱 / 道具 / 场景 / 风格 / 音色 ；#/image-edit（图像工坊）
       ├─ 分镜 #epNN（画布，每集一镜一行）
       │      范围条：‹ 集 › + 一键出片
       │      每行：首帧 / 尾帧 / 视频 + 用这张·修改 ；行内链接 ──→ 出图 ↗ / 视频 ↗
       ├─ 出图 #/frames?ep&status&char&shot=  ── 点格子：右侧抽屉（大图 + 用这张 / 修改）
       ├─ 视频 #/videos?ep=all|N&state=&shot= ── 点格子：右侧抽屉（播放 + 用这版 / 修改；缺帧 → 出图）
       └─ 成片 #/cut ── 范围条 + 一键出片；每集整集预览（ASSEMBLY 做全集视图）
右侧：待你看 #/queue · 反馈抽屉 · 系统状态面板 · 工具▾
```

后退：所有跳转用 hash（`location.hash` / `<a href>`），浏览器后退回到上一页；页内筛选（ep、state、status）用 `history.replaceState`，不压栈，所以后退直接回到来源页而不是逐个筛选条件退。抽屉的 `shot=` 在打开时写入地址，刷新能恢复。

## 3 同一对象在各页的展示（一致性）

| 生成状态 | 出图页 GenLamp、视频页呼吸点、画布 is-rendering、总览 sea-busy | 部分：呼吸灯同一 `ns-breathe`；文案不同 | 同上，词表统一 |

## 7 迭代记录（总调度 18:0x 要求做满 3 轮）

### 第 1 轮：文案与镜头参数（对照 L-123 和项目方格式）
- 改了：
  - “用这张，或不要 / 用这版，或不要” 改成“…或修改”（`v3/status.ts`）。
  - “打回 / 坏图 / 打回” 的界面文案改成“用这版 / 修改 / 待修改”（`Canvas.tsx`、`NewScriptPage.tsx`、`SeasonPage.tsx`、`status.ts`）。
  - 镜头参数写法抽成共享文件 `v3/lens.ts`（`leicaLens`、`leicaLine`）；分镜行用 `leicaLine`，现在显示“实拍 SUMMICRON-M 50mm F2 · 计划 85mm F1.2”，光圈大写。总览同一个函数（`FilmOverview` 改为从 lens.ts 引用）。
  - 分镜页顶部黄条“N 镜待补：人物造型 / 单品对照表有更新，系统正在刷新”：系统自己刷新的事不再占横条，只剩一个小呼吸灯，悬停才有说明（`StoryboardTable.tsx`，`isSysText` 加了这两句）。真正缺分镜字段时黄条照旧。
- 截图：`r1_canvas_1280x800.png`、`r1_canvas_1440x900.png`（1280 已看）。
- 还剩：反馈系统里的“被打回”是反馈工单的状态，不是镜头审片，保留；`tests/test_l123_no_reject_ui.py` 的扫描词表没加“或不要”，需要 ASSETUX 加。

### 第 2 轮：重复与深链接
- 改了：
  - 出图页自带集下拉去掉，改读顶部范围条（`#/frames?ep=all|N`，出图页监听 hashchange）。范围条现在出图、视频、成片、画布四处统一。
  - 总览详情底栏：“打开画布”改为“在分镜打开”，加“出图”“视频”两个按钮（`#/frames|#/videos?ep=&shot=`），后退回总览。
  - 视频抽屉加“从这一镜连播”：播完自动播本范围下一个有视频的镜头，再点停止。
  - 新增共享状态词表 `v3/shotWord.ts`（灰 = 排队或没开始；琥珀呼吸 = 在出；琥珀实心 = 要你看或卡住；绿 = 定稿；没有红蓝）；视频页已改用，总览、出图页待各自接入。
- 截图：`r2_frames_1280x800.png`（出图页只剩范围条一处集选择）、`r2_videos_drawer_1280x800.png`（抽屉带“从这一镜连播”），1440 同名。
- 还剩：总览 MainTag 与出图页 GenLamp 还没切到 `shotWord`；四种镜头卡没合并成一个组件。

### 第 3 轮：三项实测（用探针，不靠判断）
- 提交 300 ms 内收下：视频抽屉点“用这版”，探针测点击到页面第一处变化 = 1 ms（按钮立刻置灰）。探针拦写请求，所以走的是失败分支（弹“没标上”提示）；成功分支的撤销条没测到。
- 只显示通过验收的图：扫了 207 个当前版本（takes.json 的 active），被隔离或作废的 = 0；出图页和视频页只读当前版和未隔离的新版。
- 全站没有技术词：在 7 个页面上扫文字（总览、剧本、资产、分镜、出图、视频、成片），命中两处：
  - 资产页“身份 LoRA”“LoRA（总表）”（ASSETUX）；
  - 成片页某一版的来源行“i2va_pika_flex seed 2176157866”（ASSEMBLY）。
  - 其余 5 页没命中。
- 另一处技术味：提交失败时提示里带“Failed to fetch”，应改成“没连上，可以再点一次”。我没改（在 `store.tsx` 的统一错误出口，范围大）。
