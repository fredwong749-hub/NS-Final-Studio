## r1：新建剧本入口（最高优先）

**问题**
入口不见了。原因：UX5 D2 把步骤 ① 改到了资料清单，v3 顶栏又把“剧本▾”收进了“工具▾”。查证过程见 `STATE.md §2`。另外，P1–P3 在界面上完全没有。

**改法**
- 后端 `services/api/ns_api/story_runs.py`：
  - 起异步线程，逐段调用 `run_chain.run(upto=P1…P4)`；
  - 每段的状态、轮数、花费、问题清单都能查到；
  - 提供改原文、返修、继续写、送导入（只存草稿）几个接口；
  - 测试 `tests/test_story_runs_uirsi.py`，用 mock 写作模型，不花钱。
- 前端：
  - `NewScriptPage.tsx`：提纲表单、链条、各段卡片；
  - `ScriptFlowPage`：①“新建剧本”→ ②“导入”；
  - 顶栏常驻“＋ 新建剧本”，快捷键 N；
  - 工具菜单和项目页的主按钮也改成“新建剧本”。

**截图**：`r0_script_create_*` → `r1a_new_form_*`、`r1a_run_r1_*`（P4 需返修，46 条问题）、`r1a_run_r1_p1_*`（人物 / 场景表）。

## r2：衔接（P1 → P5、P4 → 导入）

- P1 人物表、场景表每行对照资产中心：“已登记 ›”可以直接打开，“新的”表示等导入后新建并定妆。
- P4 剧本分镜按“**键**：值”排成逐镜卡片，只排版、不改字。
- 导入页：
  - 最新的稿件放在最上面，标“最新”；
  - 默认只显示最近 5 份，其余折叠（D13）；
  - 新建剧本送来的稿件标“新建剧本”，并带“看写作过程 ›”；
  - 用 `focus=` 定位并高亮那一份。
- 截图：`r2_run_p1_*`、`r2_run_p4_{1280,1440,1920}_*`、`r2_import_*`。
