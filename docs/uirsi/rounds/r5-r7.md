## r6–r7：排版

- `apps/web/scripts/snap_tokens.py`：
  - 把 1112 处 padding / margin / gap / font-size 吸到 `--sp-*`（4px 网格）和 `--fs-*` 档位上；
  - `<small>` 统一成 12px；

- 颜色：
  - `--c-accent` 深色 #5b8cff → #3f6fe6，浅色 #2f6bff → #2a62f0；
  - `--c-text-3` 两套主题都调亮或调深一档；
  - `.bad / .warn / .good` 改用 `*-text` 色；

  - 帧角标拆成“首帧 | #4”两段，“过期·需重出”按“·”分段，窄格时整段换行，不再出现单字成行，也不再被截断。
