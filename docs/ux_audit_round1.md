## A. 顶栏 + 步骤条

**1. 1600 宽下步骤⑤“成片 未合成”被 GPU 胶囊压住，文字重叠**
- 状态 / 截图：所有画布页，1600×900 深浅色都有；review_ep02_1600_dark.png、edit_ep02S2_1600_dark.png（x≈1150 处“未合成”和“出图卡 空闲”叠在一起）
- 问题：`.v3-steps` 和 `.v3-gpu` 之间没有最小间距，也没有收缩规则，ep02 / ep03 的副文字一变长就盖住了。
- 影响：每次进画布都看到，第一眼就显得乱，也读不出成片状态。
- 建议：步骤条副文字设 `max-width` 并截断；GPU 胶囊不参与 grow；宽度 <1700 时步骤副文字只留数字。
- 严重度：P1
- 代码：apps/web/src/v3/TopBarV3.tsx、v3/v3.css（.v3-steps / .v3-gpu）

**2. 1280 宽下顶栏把信息直接丢掉**
- 截图：review_ep01_1280_dark.png、review_ep02_1280_light.png、edit_ep02S2_1280_light.png
- 问题：品牌名消失；步骤②④⑤的副文字（“造型待确认 3”“1/7”“未合成”）被隐藏；GPU 胶囊仍和⑤“成片”重叠。
- 影响：笔记本上看不到本集卡在哪一步。
- 建议：1280 下把步骤条换成紧凑形式（只留圆点 + 数字，例如“② 3”），悬停看全文；GPU 胶囊缩成两个圆点。
- 严重度：P1
- 代码：TopBarV3.tsx、v3.css 媒体查询

**3. 首屏顶栏分两次渲染，有布局跳动**
- 截图：review_why_pop.png（步骤副文字还没出来，GPU 胶囊显示“显卡…”）
- 问题：sop 和 looks 数据晚到约 1 s，步骤条宽度变化，整排按钮左右跳一下。

- 严重度：P2
- 代码：TopBarV3.tsx（useSop / useEpisodeLooks）

**4. 步骤①“剧本 1 镜待补”和工具栏“分镜字段齐全”互相矛盾**
- 截图：review_ep02_1600_dark.png
- 问题：ep02 同一屏里，顶栏说“1 镜待补”，工具栏绿色胶囊说“分镜字段齐全”，两处的判定来源不同。
- 影响：不知道该不该回去补剧本（P原则5）。
- 建议：两处共用一个判定；如果“待补”指的是 H3 / 配乐这类非分镜字段，就写明“1 镜缺配乐”。
- 严重度：P1
- 代码：TopBarV3.tsx（sop.counts.S1）、v3/Canvas.tsx（分镜字段胶囊）、v3/StoryboardDetails.tsx

**5. “队列空 · 失败 2”常驻红色，点开只能看到历史 OOM 堆栈**
- 截图：jobs_drawer.png
- 问题：失败数不会因为后来重跑成功而消失；红色提示一直挂着，就失去了提醒作用。
- 建议：同镜同阶段后来有一次成功，就把旧失败算作“已解决”；胶囊只统计未解决的失败，并且可以“全部标为已看”。
- 严重度：P2
- 代码：TopBarV3.tsx（failed 计数）、components/Drawer.tsx

## B. 审片模式（一镜一行）

**6. 同一镜有两个“当前首帧”：行里显示定稿 #5 是一张纯色占位图，点开全屏却是另一张 v4**
- 截图：review_ep02_1600_dark.png（S1 首帧 #5“已定稿”是棕色方块）、review_click_image.png（点开显示“首帧 v4 当前”，是真图）、review_watch_video.png（串播把棕色块当封面）
- 问题：ep02-S1 定稿的 `image_005_…_final.png` 实际只有 **64×112 px、256 字节**，是一张纯色测试图。行格、片段条、精修、串播封面都用它；全屏查看器走旧的 gpu3 链，显示 v4。界面不检查分辨率，就让它当了“已定稿”。
- 影响：项目方会以为 S1 已经定稿可以出片，实际定稿图是坏的；两个入口给出两张不同的图，到底以哪张为准，没法判断。
- 建议：① 定稿 / 显示时检查尺寸（宽 <512 或文件 <10 KB 就标红“图片异常”）；② 全屏查看器、行格、精修统一读 frameState 的定稿版本（P原则5）；③ 版本号统一写“#n”，不要一处写 #、一处写 v。
- 严重度：**P0**
- 代码：v3/status.ts（lockedN / frameState）、components/Viewer.tsx（仍读旧链，标题写“请 gpu3 重出首帧”）、v3/ReviewRow.tsx

**7. 视频“待你审”，但精修里没有“通过 / 打回”**
- 截图：edit_ep02S2_1600_dark.png、edit_tab_版本.png、edit_video_more_menu.png
- 问题：ep02 有 11 镜写着“待你审视频”。精修的视频格下面只有“重新出视频 / 改参数重渲… / ⋯”，⋯ 菜单里也没有“通过”。通过只能从审片行的 ⋯ 菜单进，或者在串播里按 A（还要求先完整播一遍），或者在片段条多选后点。审片行的主按钮“看视频”打开的是旧串播页。
- 影响：最常用的一步（看完视频就定）要绕三处，片段条一直停在“待你审 11”。
- 建议：视频大格正下方放“通过这版视频 ✓”“打回…”（和“定稿首帧 #n”同一个位置、同一种样式）。审片行的主按钮在视频已看完后直接变成“通过”。
- 严重度：**P0**
- 代码：v3/edit/EditCenter.tsx（slot==="video" 那段按钮）、v3/status.ts（STATUS_TABLE.review_video）

**8. “待你决定”条只能看、不能决定，而且用了内部 id**
- 截图：review_ep01_1600_dark.png、review_ep03_1600_dark.png、review_ep01_1280_dark.png
- 问题：芯片文字是“确认造型：chen_yu / gu_chen / lin_wan”，是角色 id，不是中文名；“锁定第 1 集样片参数（G4）”用了关口代号。点开弹层只有说明，加一行“你本人执行 `<命令>`”（Canvas.tsx DecideBar 里的 a.cli），界面里没有确认按钮。
- 影响：项目方唯一必须本人拍板的几件事，在画布里做不了（E5 造型确认、spec §3）。
- 建议：用中文名（林晚 / 顾沉 / 陈宇）；芯片点开就是确认面板（造型 A/B/C 大图 + “确认本集用这套”）；G4 写成“锁定第 1 集样片的出图参数”。
- 严重度：**P0**（工作流缺口）
- 代码：v3/Canvas.tsx DecideBar、后端 sop owner_actions

**9. 1280 宽下“待你决定”条挤爆工具栏**

**11. 行里的“首帧 #3”没标过期，精修里同一张标了“过期”，状态句还是“待你审首帧，满意就定稿”**

**14. ↑ / ↓ 是切集，不是切镜**
- 状态：审片模式，选中 ep02-S1 后按 ↓，结果跳到 #ep03-S1（已实测）
- 问题：一镜一行的竖向列表，正常人按 ↓ 是想去下一行；现在会把人整集带走。←/→ 才是切镜。
- 建议：审片模式下 ↑/↓ = 上一镜 / 下一镜，切集改用 PgUp / PgDn 或 Alt+↑↓。快捷键帮助同步更新（现在帮助里还写着“Enter 聚焦检查器”“L 锁定（待后端）”这些旧说明，见 tool_help.png）。
- 严重度：P1
- 代码：apps/web/src/keymap.ts、components/Dialogs.tsx HelpDialog
