## 二、本轮新问题

**N1. 视频同时是“已定稿”和“待你审”；整集出片把这些视频当作已完成跳过**
- 状态 / 截图：ep02 精修 S2 视频 #3 右上角绿色“已定稿”，状态胶囊却是“待你审视频”，“通过这版视频”还不能点（edit_video_compare_prev.png、edit_ep02S2_1600_dark.png）。整集出片弹层写“已定稿且没过期的 33 步跳过”，按钮是“都已是最新，无需出”（produce_dialog_ep02_1600_dark.png）。其中 S2 / S4 / S6 是 EB 实测时“自动测试定稿”出来的（进度弹层写“视频：完成 · gpu33:1 · v3 · 自动测试定稿”），界面上和项目方本人定稿用的是同一个绿色角标。
- 问题：视频的“定稿”（lock）和“通过”（review）是两个概念，界面只显示前一个；自动定稿也没有任何标记。
- 影响：项目方会以为这些视频已经确认过；整集出片也不会再动它们。
- 建议：视频只保留一个对项目方可见的状态，就是“通过”。自动测试定稿用灰色或虚线“测试定稿·待你复审”，并且不计入“已定稿”。
- 严重度：P1
- 代码：v3/edit/Stage.tsx / EditCenter.tsx（定稿角标）、v3/status.ts、services/api/ns_api/episode_produce.py（跳过判定）

## 三、端到端流程（项目方每天要做的）

**(a) 打开一集 → 审一镜 → 改提示词 → 重出首帧 → 对比 → 定稿 → 尾帧 → 视频 → 通过**
大约 13 次点击，加上两段长等待。
- 步骤：选集 1 → 选行 1 → Enter 进精修 1 → 点首帧小格让它变成大格 1 → 在右栏改提示词 → “保存并重出首帧” 1 → 等 → 双击新版本和上一版对比 1 → **别按 Esc**（会退出精修，N2），点回单格 1 → “定稿首帧” 1 → 点尾帧细条“出尾帧” 1 → 定稿尾帧 1 → 出视频 1 → 等（写的是约 13–17 分钟）→ 完整看一遍 → “通过这版视频 A” 1。
- 摩擦点：
  - 预计“约 1 秒”不可信（N5）。
  - 版本“双击对比”不好发现（只有一行灰色小字说明）。
  - Esc 会丢掉精修（N2）。
  - 视频绿色“已定稿”和“待你审”同时出现（N1）。
  - 用卡写的是机器名（N7）。
- 已经顺畅的部分：修改面板不再盖住大图，过期时不让定稿，通过后自动跳到下一个待审镜头。

**(b) 给一镜换某个角色的服装，看影响**
大约 6–7 次点击：选行 → Enter → 点“本镜参考”里的人物卡 → 在服装行里横向滚动找单品（25 件以上，没有搜索）→ 点单品 → “下一步：选范围、看影响” → “只应用 / 应用并重出首帧”。
- 影响面预览做得好：列出了过期镜头和衔接风险（S4→S5、S5→S6）。
- 摩擦点：
  - 影响面只写“S5 过期 → 重出首帧”，没写这镜的尾帧和视频也会跟着作废。
  - 衔接风险没有缩略图，没法直接对比。
  - 面板是模态的，选单品时看不到当前首帧。
  - 整套形象写“无图”，和资产页不一致（#31）。

**(c) 出整集**
2 次点击：“整集出片” → “开始”。
- 默认值是对的：每步等我定稿；开始前能看到步数和时长。
- 摩擦点：
  - 没有前置关口提示，超长镜头会无限等（N6）。
  - 跑完以后进度没地方看（N8）。
  - 按“每步等我定稿”跑，后面还要逐镜进精修定稿：7 镜 × 2 次定稿 + 7 次通过，约 21 次点击。审片行可以多选批量通过，但没有“批量定稿首帧”。

**(d) 从提纲写剧本并送去导入**
大约 7 次点击，加两段等待：步骤① 或 工具 → 剧本创作 1 → 粘贴提纲 → 改起止集 2（默认 1–1，N17）→ “开始写作（第 1 集）” 1（下面显示预计费用）→ 等 → “去导入页” 1 → “校验格式” 1（约 1 分钟）→ 勾选“我是项目方” 1 → “导入” 1。
- 摩擦点：
  - 提纲框只有 180 px 高（#41）。
  - 导入页的草稿分不出来（都叫 script.md），说明里还是开发路径（#42）。
  - 旧稿显示“格式问题 716”，按钮写“仍然导入”，旁边没有任何解释。
- 测试只做到“开始写作”和“导入”之前，这两个按钮都没点。
