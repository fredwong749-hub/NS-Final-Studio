## 三、四个日常流程的点击数（前 = 第 3 轮实测；后 = 本轮）

| 流程 | 前 | 后 | 说明 |
|---|---|---|---|
| (a) 审一镜并迭代首帧（打开一集 → 审 → 改提示词重出 → 对比 → 定稿 → 尾帧 → 视频 → 通过） | 约 12 次 + 2 段等待 | **约 9 次 + 2 段等待** | 定稿首帧 → 出尾帧、定稿尾帧 → 出视频各合成一步（XYQ 已做）；换集从下拉直接看到哪集在审。本轮在精修里把审视频的按钮挪到首尾帧旁边，鼠标移动距离变短，视频大格大了 76%，点击数不变 |
| (b) 锁定并出视频；视频结尾定住时换尾帧用法重出 | 定稿尾帧 1 + 出视频 1；换尾帧用法：界面上做不到 | 定稿尾帧 → 出视频 1；换尾帧用法 3（改参数重渲 → 只用首帧 → 重渲视频） | 质检角标和“尾帧怎么用”的说明联动，不用自己判断 |
| (c) 批量出一集 | 开始 2 次 + 之后约 21 次逐镜定稿 | 开始 2 次 + 批量定稿约 4 次 | 片段条：多选 → 选中待审 → 批量定稿（XYQ）。本轮：换集列表能看出哪几集已有首帧没视频；“资料不全”角标提前告诉你哪些镜整集出片会跳过 |
| (d) 换某个角色的服装 / 场景参考 | 6 次（加打字搜索） | **5 次** | 精修里直接点左栏资产库里标“本镜”的卡（不用先找本镜参考条）→ 搜单品 → 选 → 看影响 → 应用。单品名不再带“（产品）” |

## 四、宽度和字号

- 1280×800、1440×900、1600×900、1920×1080，审片和精修都实测过：
  - 没有横向滚动，document.scrollWidth 等于视口宽；
  - 可见文字没有小于 12 px 的；
  - 浅色主题也查过（after_review_1600_light、after_ep_picker_1600_light）。
- 按钮：新加的控件只用 24、28、34 px 三档高度。圆角：矩形用 var(--r-1)，胶囊用 999。
