# V2 方向（项目方 11-02 19:0x 原话，决定 L-127；取代 SCRIPT_BRIEF 里已作废的旧输入）

> “故事不过关。你分析 inbox 的衣服、配饰（乳环、阴环），是一个模特女孩对金钱和爱情的故事，3 个男人胡扯的混乱暧昧、淫乱、偷情、背叛，却依然希望变成白富美的新一年 00 后故事。你用 fable 去写，然后去思考如何把画面、故事情节……我需要时尚杂志风格，色彩艳丽的画面，运动镜头类似现在 Vogue 的子弹运动运镜头拍摄手段，画面追求 4k 电影级别，浓郁色彩。背景音乐一致性，有都市生活的音乐。音色也是上海风格时尚风格。”

## 故事
- **主题（项目方 19:1x 原话）**：“剧本为上海时尚模特的幻想和现实的挣扎。”幻想（金钱、爱情、白富美）和现实来回拉扯，三个男人的关系是这场挣扎的外在表现；画面上幻想段和现实段要有区分。
- 女主：模特，00 后，长相按 assets_v2 的 lead_f 身份脸；服装只有 O1–O4，鞋 SH1 / SH2，身体饰品 J1 / J2（只在本地亲密镜里出现）。人物性格和故事要从这些资产推出来：漆皮、风衣、铆钉、身体饰品说明她是什么样的人、在什么场合穿什么。
- 主线：她对金钱和爱情的追逐；和 3 个男人之间混乱的暧昧、偷情、背叛；想在新的一年变成白富美。
- 时间：新年前后（跨年到新年），都市（上海式的时尚都市生活）。
- 人物全部新设计，全部 ≥22 岁，关系都是成年人之间、自愿的；虚构人物。亲密戏是本地占位，文字写法不露骨（硬约束不变）。
- 由 Fable 写（SCRIPTWRITER，HOLLYWOOD 牵头），技术规则照旧（v3、H23–H25、K-WRT-211 / 212、QW-W13 / W14），V2 整季强制。

## 画面
- 时尚杂志风格：色彩艳丽、浓郁、饱和；4K 电影级。
- 运镜：类似现在 Vogue 的子弹时间式运动镜头（环绕定格、高速环绕、慢动作里的高速推拉）。新运镜要先用 Pika 做 A/B，确认能稳定出效果，再写进运镜词表（L-107），剧本按词表写。
- 调色：新做一套 V2 调色预设（不用 V1 的 S★ R0），样片交项目方挑。

## 声音
- 背景音乐：都市生活风格，整季保持一致（集级配乐，剪辑锁定后再配，L-118）。
- 配音音色：上海风格、时尚感；每个角色的音色先出试听，交项目方挑。

## 流程
P1 故事线（交项目方）→ P2–P4 → 导入 → 资产（其他人物和场景的设定图由项目方挑）→ 金样镜 → 金样集 → 铺开。风格方案（调色、运镜、音乐、音色）和剧本并行准备，在金样镜之前定稿。
