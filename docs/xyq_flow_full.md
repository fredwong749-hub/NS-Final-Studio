## 3. 模型与参数（UI 和接口里看到的名称）

- **视频（故事板可选）**：Seedance 2.5（480/720/1080p，4–30 秒）、Wan 3.0、Seedance 2.0 VIP（到 4K，4–15 秒）、**Seedance 2.0 Fast VIP（默认，480/720p，6 积分/秒）**、Seedance 2.0 Mini（4–15 秒）。时长档位：~5s / ~10s / ~15s；Seed 可选随机或固定。
- 价目表（benefit_metadata，积分/秒）：SD2.0 Fast 720p 6；Mini 720p 6、480p 5；SD2.5 480p 12、720p 20、带参考 720p 26、1080p 64、4K 99；SD2.5 Draft 样片 480p 7–9；**MiniMax H3 768p 9、2K 14、H3 max 480p 5**（平台上也有 H3）；Wan3 720p 14。
- **图片**：智能图片 V2.5 Pro / Fast、V2、Seedream 5.0 Pro / Flash / Lite、4.x、Anycook 影视版、美学模型 8.2 等。角色和场景图默认用智能图片 V2.5 Pro 1K。
- **风格**：项目级“国产高颜值现偶风”。风格词会作为前缀加在每次生成前（style_pe_before：“实拍摄影写实，国产高美感偶像剧胶片感剧照……”，model_key AnyDream_2.0）。
- **配音口音**：SD2.5 支持中文 / 英文，口音可选普通话、东北话、粤语、四川话等，默认“智能推荐”。

## 4. 一致性、首尾帧、对白、连续性：它怎么做

- **角色一致性**：角色 → 造型（同一人不同服装各算一个资产），每个造型一张全身正面白底立绘。立绘提示词很长、按结构写（脸型、眉眼、鼻唇、发型、服装材质、配饰、鞋，开头写“水平正视全身立绘完整包含双足”），存在节点上。片段提示词里每句主语都用 @造型 引用。片段卡上方直接显示参考缩略图（场景图 + 角色图）。
- **首尾帧**：**没有。** 参考图 + 文本直接生成视频（R2V），不做首帧定稿。
- **镜头连续**：一个片段 ≤15 秒，里面写 2–3 个分镜并各自标时长，由模型在一次生成里切镜。我们的镜2 + 镜3 被合成了一个片段。连续性主要靠“同一次生成”和“每个片段固定一张场景子图”。
- **对白 / 口型**：写在视频提示词里，例如“@顾沉 以从容、低声的语气说：‘蓝头发，很大胆。’”；内心独白写成“在心里想：‘…’”，再加一句“画面中所有出镜角色全程不说话，内心声音清楚压过大堂杂声”。环境声也逐条写。人声和音效由 Seedance 一起生成，不另外做 TTS（推断，没出片验证）。
- **BGM**：片段条上单独有“生成配乐”，整集统一做。“添加字幕”也在这里。
- **编辑和重出**：片段卡上有“引用 / 编辑 / 立即生成”；“故事板助手”可以用对话改；资产节点下面的“+”出变体；“多选”可以批量出片段（这次没用）。

## 5. 画质对比（vs 我们 ep02 H3）

**没法比：没有出片。** 两段视频都被同意框拦在生成前。动作流畅度、抖动、肢体、脸部一致性都没测到。能比的只有静态资产：
- 角色立绘：干净的棚拍全身白底，人脸偏“现偶网红脸”，风格统一，适合当参考图。但这只是参考图，不等于成片里的脸，它的脸部一致性要看成片才知道。
- 场景图（旋转门、电梯）：写实、透视正确，光线和剧本一致（清晨斜照、金属反光）。

要做真正的画质对比，需要项目方本人点“同意并继续”。之后再生成片段 01、02（约 168 积分），在页面里看完截帧，和 `data/episodes/ep02_PREVIEW_未完成_H3原声.mp4` 对比。

## 6. 我们该抄什么

流水线逻辑：
1. **结构化的视频提示词模板**：场景锚定句 + “由 N 个分镜组成” + 每个分镜写（时长、景别、机位、构图左右位置、@角色·造型 + 动作、摄影机运动、声音）。对白写语气和说话人；独白写成“在心里想”，并明确“出镜角色不张嘴”。可以直接借来改进我们 motion 提示词的组装（只改格式，剧本文字照原样传）。
2. **资产 = 角色 × 造型 + 场景 × 子场景**，每个资产一张标准立绘或设定图，再加一段结构化的外观描述；生成时按片段自动带上对应参考图。我们可以把造型和子场景做成一等资产，每镜自动带参考。
3. **一次生成里多切镜**（10–15 秒带 2–3 个分镜）来保证连续。可以在我们的 H3 / Seedance 线路上试一下“合镜”，和单镜 + 首尾帧方案做 A/B。
4. 剧本分析和分镜脚本**按集、按字数计费**，并且规划方式（15s / 30s）在生成前选定。
5. 单独的“生成配乐 / 添加字幕 / 多轨编辑器”放在整集层面做，不放进单镜。

UI：
6. 生成按钮上直接写积分和原价（✦84 ~~154~~），批量按钮也写合计（✦2、✦4）。
7. 流程门槛用“下一步”加缺项提示（“部分角色形象未就绪…去完善 / 仍要继续”），不硬拦。
8. 资产卡状态用红字写“请完善 N 个角色形象 / 子场景图”。分集卡写“分镜视频 0/7”和“15s 上限”标签。
9. 片段卡上方放参考缩略图，正文里 @ 芯片高亮，一眼能看出这一镜用了哪些参考。

不抄：去掉首尾帧（我们 C3 要求保留）；对话式助手（写作走外部网关）。
