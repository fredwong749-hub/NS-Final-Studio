# NS-Final Studio · 调研 v7：林晚美甲（B5）

> 日期：2026-10-30。对应 REQUIREMENTS B5：手指甲约 5 cm 透明延长甲、满钻；脚趾甲约 2 cm、性感款。资产规格与参考图规则沿用 v6 §4。均未实测；⚠ = 单一来源、二手来源或推断。

## 0. 结论

1. **趋势支撑充分：** 2026 年秋季，“珠宝甲 / 满钻甲”（bedazzled、jewellery nails、junk nails）回潮，Dazed 称“clean girl 甲已死”。玻璃甲升级为立体的“吹制玻璃甲”（blown-glass）。透明底配大颗钻适合长尖甲（stiletto）。中文侧热词：冰透甲、冰透碎钻、满钻 / 堆钻 / 拼钻、长尖甲 + 猫眼 + 大钻。
2. **甲型：** 5 cm 只建议用尖头（stiletto）、芭蕾 / 梯形（coffin）、长杏仁（almond）三种。尖头最显长，也最贴近林晚“冷艳 + 甜”的气质。
3. **颜色锚点：** 冰蓝（发色）、冷白（肤色）、草莓粉（项链、唇色）。底色保持透明或冰透，钻以白钻 / 极光钻为主，粉钻 / 草莓为点缀，避免抢走脸部焦点。
4. **最大风险在视频：** 长甲 + 钻在 H3 运动中容易闪烁、变短或糊掉。解决办法是少给手动作、做尾帧、后期修补（见 §4）。

## 4. 出图与视频可靠性

**模型能力**
- Qwen Image 2.1 / FLUX.2 Klein 都没有专门的手部或长甲测评。
  - Klein 4B 的 UniGenBench 手部分约 69–76，社区反映多指、怪手仍然常见 ⚠。
  - Qwen 2.0 时代的修手测试中，编辑模型会大幅改动手的位置 ⚠。
- **推断风险：** 长甲会被画短或断甲；十指甲长不一致；钻石糊成光斑或变成颗粒噪点；透明甲被画成白色。

**提示词要点**
- 写比例而不写厘米。
- 写“手掌放松、五指自然张开、彼此不交叠”。
- 钻写“清晰的刻面反光”而不是“闪闪发光”（后者会出光晕和星芒）。
- 透明写“透明甲下可见指尖皮肤”。
- 灯光写“柔和侧光 + 小点状高光”，避免逆光爆闪。

**资产规格**（v6 单品格式；入库前人工数手指、量甲长）

- **制作：** 先用 Qwen Base 文生图出甲型，选定后再用 Base + Consistency LoRA 编辑出各角度。画面只出手或脚，不带脸和身体，以免多参考时串入。

**多参考使用**（v6 §4.2 规则 3、4）
- 美甲图只在手部特写或近景、且手有动作时加入。
- 优先级最低（脸 > Look > 鞋 > 甲）。
- 提示词写：`<image3>只提供指甲的甲型、长度、透明度与钻饰布局，不要沿用其手势、肤色和背景`。
- 中景及更远的景别不加图，只用一句文字锁：`超长透明尖头满钻美甲`。
- 足部镜头同理，用 TOE 图替代鞋图，或与鞋图二选一。

**MiniMax H3 视频**
- 没有找到 H3 关于手或首饰的专门测评。业界通用经验：扩散视频模型难以在时间上稳住高细节小几何体；首饰大幅运动会导致刻面变形；反光材质的漂移更难察觉 ⚠。
- **预期问题：** 钻光逐帧闪烁、甲长缩短、手指融合、链条消失。
- **缓解办法：**
  1. 手部动作慢、幅度小，避免手指快速开合和手背翻转。
  2. 手部动作镜头做首尾帧（v6 §5），两帧都是同款甲，以锁住长度。
  3. 在动作句中重复“超长透明满钻尖甲”。
  4. 远景让手出画或垂放。
  5. 后期逐帧检查；问题段用首帧局部遮罩回贴，或在剪辑上避开。
  6. 不加“闪烁 / sparkle”动态描述，让高光自然随光变化。
