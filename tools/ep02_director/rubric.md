# DIR 审片评分标准（rubric v1，2026-10-31）

只评**技术与剪辑**：画面、运动、声音、剪辑节奏。**不评剧本内容、台词、表演意图**；不做内容检测。
每一版 ep 成片都按这 7 维打 0–10 分。**每一维 ≥7 才算"可以给项目方看"**；任何一维 <5 = 这一版不出门。

工具：`tools/ep02_director/review.py`（逐镜数字 + 接触印样），`tools/ep02_director/red_trace.py`（脸部泛红逐帧追踪）。
机器指标只是"预评分 / 线索"，最终分由 DIR 看过 `sheets/*.jpg`、`overview.jpg`、`color_timeline.png` 后定。
阈值写在 `review.py` 顶部常量里；改动要同步 `docs/ep02_iter/LEARNED_SPECS.md`。

---

## ① 人物一致性（同一个人从头到尾像同一个人）

| 分 | 标准 |
|---|---|
| 9–10 | 每镜林晚 SFace 对参考余弦中位 ≥0.40；跨镜与"林晚平均脸"余弦全部 ≥0.75；发色（浅冰蓝）每帧都对；看印样认不出差别 |
| **7（及格）** | 每镜参考余弦中位 ≥0.30（项目锁定闸门 Q-D1）；跨镜 ≥0.65；镜内与本镜平均脸最低余弦 ≥0.60（没有"中途换脸"）；发色无明显跳变 |
| 5 | 有 1 镜 <0.30 或某镜中途脸明显变了 |
| ≤3 | 多镜像不同的人 |

测量：YuNet+SFace（`models_cache/vision`）；浅蓝发得分（头顶带+两侧带蓝色像素，H85–125 S≥60 V≥40）≥0.35 且最高者 = 林晚。
注意：参考图 `assets/characters/lin_wan/lin_wan.png` 是棚拍正脸，夜景侧脸天然偏低 0.05–0.1；低于 0.30 时一定回看印样。

## ② 画面连贯 / 无鬼影、多肢、穿模

| 分 | 标准 |
|---|---|
| 9–10 | 逐帧看动作段（印样 + 半速条带）无叠影、无多手多脚、无手指融合、无物体凭空出现/消失 |
| **7（及格）** | 允许快动作中 ≤2 帧轻微运动模糊，但不能看出"两只脚 / 两只手"；`ghost_low_p95` 不比同镜基模版高 0.1 以上 |
| 5 | 有 1 处观众能察觉的叠影（如 v0 S1 第 76–92 帧前脚叠成两只鞋） |
| ≤3 | 多处多肢 / 肢体融合 |

自动指标（下半身鬼影比）区分力弱，**必须看图**：腿 / 手入画的镜头用 `tools/motion_judder.py` 条带图逐帧看。

## ③ 画面细节与质感

| 分 | 标准 |
|---|---|
| 9–10 | 脸部有毛孔/发丝级细节，无蜡像磨皮、无 AI 油光、无过锐白边；暗部有层次不发灰不死黑 |
| **7（及格）** | 1080×1920 全屏看脸不糊（脸内 Laplacian 方差中位 ≥60 @128 px 宽脸块，仅作参考），无明显块效应 / 色带；无锐化光晕 |
| 5 | 有镜头明显糊或磨皮塑料感 |
| ≤3 | 多镜糊 / 有压缩块 |

## ④ 运动自然度 / 卡顿

| 分 | 标准 |
|---|---|
| 9–10 | 每镜都有与景别相称的连续运动；J4 <1.10 或 z <2；无开头/结尾定住；节奏不拖 |
| **7（及格）** | 静止占比（96×168 帧差 <0.35）<50% 的镜 ≥90%；结尾定住 <0.5 s；J4 z ≥3 的镜 ≤1；无"停帧"（stall_frac <0.05） |
| 5 | 1/3 镜头基本不动或结尾明显定住 |
| ≤3 | 大部分镜头像幻灯片 |

## ⑤ 短剧观感（只评剪辑与技术：景别、节奏、切点、开场钩子的剪辑处理）

| 分 | 标准 |
|---|---|
| 9–10 | 竖屏短剧节奏：平均每刀 2–4 s，最长单镜 ≤6 s（有强动作除外）；景别相邻不重复（特写/近景/中景交替）；前 3 s 内至少 1 个切点或强运动、画面第一帧就有人物；切点无闪帧、黑帧 |
| **7（及格）** | 平均每刀 ≤5 s；相邻同景别切 ≤30%；前 3 s 有运动（节奏 ≥1 px/帧）或切点；切点无闪帧/黑帧/音频爆音；没有任何一镜"画面定住等台词" |
| 5 | 平均每刀 >6 s，或连续 3 镜同景别，或开场 3 s 静止 |
| ≤3 | 一镜一句、全片同一节奏的"PPT 感" |

这一维只看剪辑手法（切多快、切在哪、景别怎么排、开头怎么剪），不评故事本身。

## ⑥ 声画配合（对白同步、配乐/环境声、响度）

| 分 | 标准 |
|---|---|
| 9–10 | 整集 −14 LUFS ±1、真峰值 ≤−1 dBTP；对白期间说话人嘴动与语音包络相关 ≥0.4、偏移 ≤±80 ms；没有两条人声叠在一起；配乐在对白下自动压低；切点前后电平跳变 <10 dB 且无爆音 |
| **7（及格）** | −14 ±1.5 LUFS、TP ≤−1；可测对白中 ≥70% 句子嘴部相关 ≥0.3 且 |偏移| ≤120 ms（画外音不计）；无人声重叠；无 >1 s 的意外静音；无爆音 |
| 5 | 有对白嘴不动 / 嘴动无声，或人声互相盖住 |
| ≤3 | 大面积不同步或响度失控 |

嘴部同步是代理指标（嘴部帧差能量 vs 300–3400 Hz 包络互相关，混音里有配乐会拉低相关），低分句必须回放确认。

## ⑦ 调色统一

| 分 | 标准 |
|---|---|
| 9–10 | 同一场景跨镜脸部平均色 ΔE76 ≤4；镜内脸颊 a*p95 漂移 ≤4；无任何"脸突然泛红/发绿"；整帧无红色异常块 |
| **7（及格）** | 跨镜同一人脸部 ΔE ≤6；镜内脸颊 a*p95 相对开头 0.5 s 漂移 ≤6，且脸颊 a*≥25 像素占比 ≤25%（v0 正常镜 0–10%）；整帧红色异常最大连通块 <1% 画面；文件色彩标记全片统一（bt709） |
| 5 | 有 1 镜脸颊明显泛红（占比 25–40%）或跨镜色偏一眼可见 |
| ≤3 | 多镜脸部泛红 / 色偏（如 Pika 只给首帧 S2：脸颊 a*p95 17→44，52% 像素 a*≥25） |

## 打分流程

1. `review.py episode <成片> <timeline> --name vN_xxx` → 读 `review.md` 机器预评分和自动标记。
2. 看 `overview.jpg`（每镜首/中/尾）→ 节奏、景别、调色一眼判断。
3. 每个有标记的镜头读 `sheets/<镜>.jpg`（红色表头 = 该帧脸颊泛红或红块）。
4. 有泛红标记 → `red_trace.py` 把 生成原片 / 去抖 / 调色 / 成片段落 / 关键帧 放一起追。
5. 写 `docs/ep02_iter/vN_review.md`：7 维分 + 每镜问题 + Top 修复项；确认的规格写进 `LEARNED_SPECS.md`。
